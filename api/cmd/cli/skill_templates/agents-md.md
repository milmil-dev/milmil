## milmil CLI

When the user wants to control milmil (their self-hosted anime media
server), run `milmil agents-guide` in the terminal to load the full
agent usage guide before performing any action. Always pass `--json`
when piping CLI output between commands. Confirm destructive operations
(`match auto`, `match undo`, `token revoke`) with the user unless they
explicitly ask you to run with `--yes`.
