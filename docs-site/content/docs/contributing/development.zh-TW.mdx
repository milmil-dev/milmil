## 前置條件

- **Go 1.26+** — 後端 API
- **Bun 1.3+** — 前端建置工具
- **FFmpeg** — 媒體處理
- **Docker** — 用於 PostgreSQL 和 Redis（或在本機安裝）

## 開始使用

<Tabs items={["全端", "僅後端", "僅前端"]}>
<Tab value="全端">

<Steps>
<Step>
### 複製儲存庫

```bash
git clone https://github.com/milmil-dev/milmil.git
cd milmil
```
</Step>
<Step>
### 啟動基礎設施

```bash
docker compose -f docker-compose.dev.yml up -d
```

這會啟動供開發使用的 PostgreSQL 和 Redis。
</Step>
<Step>
### 啟動後端

```bash
cd api
cp .env.example .env
go mod download
make dev
```

API 伺服器會在 `http://localhost:8080` 啟動，並支援熱重載。
</Step>
<Step>
### 啟動前端

```bash
cd web
bun install
bun run dev
```

開發伺服器會在 `http://localhost:5173` 啟動，並支援 HMR。
</Step>
</Steps>

## Pull Request 指南

1. Fork 儲存庫並建立功能分支
2. 為新功能撰寫測試
3. 確保 `make lint` 和 `make test` 通過
4. 保持 PR 精簡 — 每個 PR 只處理一個功能或修正
5. 撰寫清楚的提交訊息，描述變更內容
