## ようこそ

milmil はオープンソースプロジェクトであり、コントリビューションを歓迎します！バグ修正、機能追加、ドキュメントの改善、問題の報告など、すべての貢献がプロジェクトの向上に役立ちます。

## 貢献の方法

- **コード** — バグ修正、機能の実装、パフォーマンスの改善
- **ドキュメント** — ドキュメントの改善、翻訳の追加、タイポの修正
- **バグレポート** — 詳細な再現手順を含む問題の報告
- **機能リクエスト** — 新機能や改善の提案
- **翻訳** — UI とドキュメントの新しい言語への翻訳

## 行動規範

礼儀正しく、建設的であること。私たちは [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) の行動規範に従います。
