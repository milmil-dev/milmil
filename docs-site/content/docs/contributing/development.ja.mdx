## 前提条件

- **Go 1.26+** — バックエンド API
- **Bun 1.3+** — フロントエンドビルドツール
- **FFmpeg** — メディア処理
- **Docker** — PostgreSQL と Redis 用（またはローカルにインストール）

## はじめに

<Tabs items={["フルスタック", "バックエンドのみ", "フロントエンドのみ"]}>
<Tab value="フルスタック">

<Steps>
<Step>
### リポジトリをクローン

```bash
git clone https://github.com/milmil-dev/milmil.git
cd milmil
```
</Step>
<Step>
### インフラを起動

```bash
docker compose -f docker-compose.dev.yml up -d
```

開発用の PostgreSQL と Redis が起動します。
</Step>
<Step>
### バックエンドを起動

```bash
cd api
cp .env.example .env
go mod download
make dev
```

API サーバーが `http://localhost:8080` でホットリロード付きで起動します。
</Step>
<Step>
### フロントエンドを起動

```bash
cd web
bun install
bun run dev
```

開発サーバーが `http://localhost:5173` で HMR 付きで起動します。
</Step>
</Steps>

## プルリクエストのガイドライン

1. リポジトリをフォークしてフィーチャーブランチを作成
2. 新機能にはテストを記述
3. `make lint` と `make test` が通ることを確認
4. PR は集中させる — 1 つの機能またはバグ修正ごとに 1 つの PR
5. 変更内容を説明する明確なコミットメッセージを記述
