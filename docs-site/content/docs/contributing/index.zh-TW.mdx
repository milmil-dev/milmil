## 貢獻方式

- **程式碼** — 修復錯誤、實作功能、改善效能
- **文件** — 改善文件、新增翻譯、修正錯字
- **錯誤回報** — 附上詳細的重現步驟回報問題
- **功能請求** — 建議新功能或改進方案
- **翻譯** — 協助將使用者介面和文件翻譯為其他語言

## 行為準則

請保持尊重和建設性。我們遵循 [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 行為準則。
