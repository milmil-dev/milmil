## 錯誤回報

<Steps>
<Step>
### 搜尋現有問題

在提出新的錯誤報告之前，請先在 [GitHub Issues](https://github.com/milmil-dev/milmil/issues) 查看是否已有相關回報。
</Step>
<Step>
### 收集資訊

報告中請包含以下資訊：

- milmil 版本（可在 **設定 > 系統** 中查看）
- 部署方式（Docker、手動安裝）
- 作業系統和架構
- 瀏覽器及版本（針對 UI 相關錯誤）
- 相關的日誌輸出
</Step>
<Step>
### 提出問題

開啟一個[新的 issue](https://github.com/milmil-dev/milmil/issues/new)，使用清楚的標題和詳細的描述，並附上重現錯誤的步驟。
</Step>
</Steps>

<Callout type="info">
針對後端問題，請附上 `docker logs milmil-api` 的相關日誌輸出。針對前端問題，請附上瀏覽器主控台錯誤（F12 > Console）。
</Callout>

## 功能請求

在 [GitHub Discussion](https://github.com/milmil-dev/milmil/discussions) 中提出功能想法。請描述：

- 你想要達成**什麼**目標
- **為什麼**這個功能會有幫助
- 你設想的**實現方式**（選填）

## 提問與求助

如有一般性的問題，請使用 [GitHub Discussions](https://github.com/milmil-dev/milmil/discussions) 而非提出 issue。Issues 僅用於已確認的錯誤和追蹤中的工作項目。
