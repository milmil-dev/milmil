## 歡迎

milmil 係一個開源專案，歡迎任何人參與貢獻！無論你係修正 bug、新增功能、改善文件，定係回報問題，每一份貢獻都好有幫助。

  </Card>

  </Card>

## 貢獻方式

- **程式碼** — 修正 bug、實作功能、改善效能
- **文件** — 改善文件、新增翻譯、修正錯字
- **Bug 回報** — 附上詳細重現步驟嘅問題回報
- **功能請求** — 建議新功能或改善方案
- **翻譯** — 協助將 UI 同文件翻譯成其他語言

## 行為準則

請保持尊重同建設性。我哋遵循 [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 行為準則。
