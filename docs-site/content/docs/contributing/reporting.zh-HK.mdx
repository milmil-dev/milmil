## Bug 回報

<Steps>
<Step>
### 搜尋現有問題

提交新 bug 之前，先去 [GitHub Issues](https://github.com/milmil-dev/milmil/issues) 睇吓係咪已經有人回報咗。
</Step>
<Step>
### 收集資訊

喺你嘅回報入面包含：

- milmil 版本（喺 **設定 > 系統** 查看）
- 部署方式（Docker、手動）
- 作業系統同架構
- 瀏覽器同版本（UI bug 嘅話）
- 相關嘅日誌輸出
</Step>
<Step>
### 提交問題

開一個[新 issue](https://github.com/milmil-dev/milmil/issues/new)，寫清楚標題同詳細描述，並附上重現步驟。
</Step>
</Steps>

<Callout type="info">
後端問題請附上 `docker logs milmil-api` 嘅相關日誌輸出。前端問題請附上瀏覽器主控台錯誤（F12 > Console）。
</Callout>

## 功能請求

喺 [GitHub Discussions](https://github.com/milmil-dev/milmil/discussions) 開一個討論嚟提出功能建議。描述：

- **想做乜嘢** — 你想達成嘅目標
- **點解有用** — 呢個功能嘅價值
- **點樣運作**（選填）— 你設想嘅實現方式

## 問題同求助

一般問題請用 [GitHub Discussions](https://github.com/milmil-dev/milmil/discussions)，唔好開 issue。Issue 係留畀已確認嘅 bug 同要追蹤嘅工作項目。
