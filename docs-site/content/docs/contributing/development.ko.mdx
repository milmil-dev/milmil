## 사전 요구 사항

- **Go 1.26+** — 백엔드 API
- **Bun 1.3+** — 프론트엔드 빌드 도구
- **FFmpeg** — 미디어 처리
- **Docker** — PostgreSQL 및 Redis용 (또는 로컬 설치)

## 시작하기

<Tabs items={["Full Stack", "Backend Only", "Frontend Only"]}>
<Tab value="Full Stack">

<Steps>
<Step>
### 저장소 클론

```bash
git clone https://github.com/milmil-dev/milmil.git
cd milmil
```
</Step>
<Step>
### 인프라 시작

```bash
docker compose -f docker-compose.dev.yml up -d
```

개발용 PostgreSQL과 Redis를 시작합니다.
</Step>
<Step>
### 백엔드 시작

```bash
cd api
cp .env.example .env
go mod download
make dev
```

API 서버가 핫 리로드와 함께 `http://localhost:8080`에서 시작됩니다.
</Step>
<Step>
### 프론트엔드 시작

```bash
cd web
bun install
bun run dev
```

개발 서버가 HMR과 함께 `http://localhost:5173`에서 시작됩니다.
</Step>
</Steps>

</Tab>
