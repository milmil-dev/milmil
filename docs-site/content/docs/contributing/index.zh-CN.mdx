## 欢迎

milmil 是一个开源项目，欢迎各种形式的贡献！无论是修复 Bug、添加功能、完善文档还是报告问题，每一份贡献都很重要。

## 贡献方式

- **代码** — 修复 Bug、实现功能、提升性能
- **文档** — 完善文档、添加翻译、修复错别字
- **Bug 报告** — 提交带有详细复现步骤的问题报告
- **功能请求** — 建议新功能或改进
- **翻译** — 帮助将界面和文档翻译为新的语言

## 行为准则

请保持尊重和建设性。我们遵循 [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 行为准则。
