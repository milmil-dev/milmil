## 前提条件

- **Go 1.27+** — 后端 API
- **Bun 1.3+** — 前端构建工具
- **FFmpeg** — 媒体处理
- **Docker** — 用于 PostgreSQL 和 Redis（或本地安装）

## 开始开发

<Tabs items={["Full Stack", "Backend Only", "Frontend Only"]}>
<Tab value="Full Stack">

<Steps>
<Step>
### 克隆仓库

```bash
git clone https://github.com/milmil-dev/milmil.git
cd milmil
```
</Step>
<Step>
### 启动基础设施

```bash
docker compose -f docker-compose.dev.yml up -d
```

这将启动用于开发的 PostgreSQL 和 Redis。
</Step>
<Step>
### 启动后端

```bash
cd api
cp .env.example .env
go mod download
make dev
```

API 服务器将在 `http://localhost:8080` 启动，支持热重载。
</Step>
<Step>
### 启动前端

```bash
cd web
bun install
bun run dev
```

开发服务器将在 `http://localhost:5173` 启动，支持 HMR。
</Step>
</Steps>

## Pull Request 指南

1. Fork 仓库并创建功能分支
2. 为新功能编写测试
3. 确保 `make lint` 和 `make test` 通过
4. 保持 PR 聚焦 — 每个 PR 只包含一个功能或修复
5. 编写清晰的提交信息来描述变更内容
