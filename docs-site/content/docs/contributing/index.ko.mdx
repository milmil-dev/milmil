## 환영합니다

milmil은 오픈소스 프로젝트이며 기여를 환영합니다! 버그 수정, 기능 추가, 문서 개선, 이슈 보고 등 모든 기여가 도움이 됩니다.

## 기여 방법

- **코드** — 버그 수정, 기능 구현, 성능 개선
- **문서** — 문서 개선, 번역 추가, 오타 수정
- **버그 보고** — 상세한 재현 단계와 함께 이슈 보고
- **기능 요청** — 새로운 기능이나 개선 사항 제안
- **번역** — UI 및 문서를 새로운 언어로 번역 지원

## 행동 강령

존중하고 건설적으로 행동하세요. 우리는 [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 행동 강령을 따릅니다.
