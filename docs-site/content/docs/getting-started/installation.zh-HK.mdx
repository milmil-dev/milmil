## 前置條件

- **Docker**（推薦）或 Go 1.26+ 同 Bun 1.3+
- **FFmpeg** — 用於轉碼同媒體資訊擷取
- **Redis** — 選用，但推薦用喺正式環境部署

## Docker（推薦）

用 Docker Compose 執行 milmil 係最簡單嘅方式：

```bash
git clone https://github.com/milmil-dev/milmil.git
cd milmil
docker compose up -d
```

呢個會啟動所有服務：
- **PostgreSQL 16** — 資料庫
- **Redis 7** — 快取
- **milmil-api** — Go 後端（連接埠 8080）
- **milmil-web** — React 前端，透過 Nginx 提供服務（連接埠 3000）

更多進階設定請參閱 [Docker 部署](/docs/getting-started/docker)。

## 手動安裝

### 後端（Go API）

```bash
cd api
go mod download
make build
./server
```

### 前端（React SPA）

```bash
cd web
bun install
bun run build
```

用任意靜態檔案伺服器或 Nginx 託管 `web/dist` 目錄下嘅建置產物。

## 環境變數

| 變數 | 預設值 | 說明 |
|----------|---------|-------------|
| `DATABASE_URL` | `sqlite://data/milmil.db` | 資料庫連線字串 |
| `JWT_SECRET` | *必填* | JWT 簽章金鑰（至少 32 個字元） |
| `MILMIL_ENCRYPTION_KEY` | *必填* | AES-256 金鑰，用於加密儲存憑證 |
| `API_PORT` | `8080` | API 伺服器連接埠 |
| `DATA_DIR` | `./data` | 下載同轉碼快取目錄 |

所有選項請參閱 [設定](/docs/configuration/environment)。
