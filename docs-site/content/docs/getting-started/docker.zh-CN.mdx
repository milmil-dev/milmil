## 环境变量文件

milmil 将环境变量拆分为两个文件：

### `.env`（仓库根目录）— Compose 层

| 变量 | 默认值 | 用途 |
|----------|---------|---------|
| `API_PORT` | `8080` | API 绑定的宿主机端口 |
| `WEB_PORT` | `3000` | Web UI 绑定的宿主机端口 |
| `DATA_DIR` | `./data` | 挂载到容器 `/data` 的宿主机路径 |
| `MEDIA_DIR` | `/mnt/media` | 挂载到容器 `/media` 的宿主机路径（只读） |
| `DOWNLOAD_DIR` | `./downloads` | 挂载到容器 `/downloads` 的宿主机路径 |
| `POSTGRES_USER` | `milmil` | Postgres 超级用户（仅在 `--profile postgres` 时使用） |
| `POSTGRES_PASSWORD` | `change_me_postgres_password` | Postgres 密码 |
| `POSTGRES_DB` | `milmil` | Postgres 数据库名 |

### `api/.env` — 运行时密钥

| 变量 | 是否必填 | 用途 |
|----------|----------|---------|
| `JWT_SECRET` | ✅ | JWT 签名密钥（≥ 32 字符）。使用 `openssl rand -hex 32` 生成。 |
| `DATABASE_URL` | ✅ | 参见下方[数据库](#database)说明 |
| `MILMIL_ENCRYPTION_KEY` | 推荐 | 用于加密存储凭据的 AES-256 密钥。未设置时回退到 `JWT_SECRET`。 |
| `REDIS_URL` | 否 | 开发环境可留空（使用内存缓存）；生产环境设为 `redis://redis:6379`。 |
| `REDIS_USERNAME`, `REDIS_PASSWORD` | 否 | 用于 Redis 容器 ACL（API 不直接使用）。 |
| `ADMIN_USER`, `ADMIN_PASSWORD` | 否 | 首次启动时自动配置管理员账户。参见[首次设置](/docs/getting-started/first-setup)。 |
| `DANDANPLAY_APP_ID`, `DANDANPLAY_APP_SECRET` | 否 | DandanPlay 哈希匹配 + 弹幕功能。 |

完整变量列表请参阅 [`api/.env.example`](https://github.com/milmil-dev/milmil/blob/main/api/.env.example)。

## Profiles

```bash
docker compose up -d
```

启动：`api` + `web` + `redis`（使用 SQLite 数据库，不含 Postgres）。

```bash
docker compose --profile postgres up -d
```

额外启动：Postgres 16 容器。请先在 `api/.env` 中设置 `DATABASE_URL=postgres://...`。

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build
```

从本地源码构建镜像，而非从 Docker Hub 拉取。

## 服务

| 服务 | 端口 | 镜像 |
|---------|------|-------|
| `milmil-api` | 8080 | `milmildev/milmil-api:latest` |
| `milmil-web` | 3000 | `milmildev/milmil-web:latest` |
| `redis` | 6379 | `redis:alpine` |
| `postgres` | 5432 | `postgres:16-alpine`（通过 `--profile postgres` 启用） |

## 卷挂载

API 容器需要三个挂载点：

```yaml
volumes:
  - ${DATA_DIR:-./data}:/data            # app data, transcode cache, SQLite DB
  - ${MEDIA_DIR:-/mnt/media}:/media:ro   # anime library (read-only)
  - ${DOWNLOAD_DIR:-./downloads}:/downloads
```

在 `.env` 中配置宿主机路径。容器内部始终使用 `/data`、`/media`、`/downloads`，因此 milmil 内的媒体库路径应以 `/media/...` 开头。

## 数据库

<Tabs items={['SQLite', 'PostgreSQL']}>
<Tab value="SQLite">

零配置，数据存储于 `/data/milmil.db`。推荐用于单用户场景及小型媒体库。

```
DATABASE_URL=sqlite://data/milmil.db
```

</Tab>
<Tab value="PostgreSQL">

推荐用于多用户或多实例部署。迁移在启动时自动应用。

```
DATABASE_URL=postgres://milmil:change_me_postgres_password@postgres:5432/milmil?sslmode=disable
```

使用 `docker compose --profile postgres up -d` 启动服务栈。

</Tab>
</Tabs>
