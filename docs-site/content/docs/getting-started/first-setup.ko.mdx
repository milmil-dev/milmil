## 설정 마법사

milmil을 처음 열면 설정 마법사가 안내합니다:

1. **관리자 계정 생성** — 사용자 이름과 비밀번호 설정
2. **라이브러리 추가** — 애니메이션 미디어 디렉토리 지정
3. **라이브러리 스캔** — milmil이 자동으로 파일을 스캔하고 매칭

## 라이브러리 추가

milmil은 여러 스토리지 백엔드를 지원합니다:

| 유형 | 설명 |
|------|-------------|
| **로컬** | 호스트 파일 시스템의 디렉토리 |
| **SMB/CIFS** | Windows 네트워크 공유 |
| **SFTP** | SSH 파일 전송 |
| **WebDAV** | 클라우드 스토리지 (Nextcloud 등) |
| **Rclone** | 40개 이상의 클라우드 제공업체 (Google Drive, OneDrive, Dropbox, S3 등) |

### 로컬 디렉토리

가장 간단한 설정 — 애니메이션 폴더 경로만 지정하면 됩니다:

```
/media/anime
```

### 네트워크 스토리지

SMB, SFTP 또는 WebDAV의 경우 라이브러리 설정에서 연결 정보를 입력합니다. 자격 증명은 AES-256으로 암호화되어 저장됩니다.

## 메타데이터 매칭

스캔 후 milmil이 자동으로 파일을 애니메이션 항목에 매칭합니다:

1. **DandanPlay** — 파일 해시 매칭 (가장 정확)
2. **Bangumi** — 제목 기반 매칭
3. **AniList** — 대체 메타데이터 소스

매칭되지 않은 파일은 라이브러리 상세 페이지에서 수동으로 매칭할 수 있습니다.
