title: 平台特定說明
description: Synology、Unraid、TrueNAS 同 Raspberry Pi 相對標準 Docker Compose 安裝嘅差異說明。
---

<Callout type="info">
請先跟標準 [安裝](/docs/getting-started/installation) 指南操作。呢頁只記錄各平台有咩唔同。
</Callout>

## Synology NAS（DSM 7+）

1. 喺套件中心安裝 **Container Manager**。
2. SSH 入去並建立 `/volume1/docker/milmil/`。
3. 將專案嘅 `docker-compose.yml`、`.env` 同 `api/.env` 複製到該資料夾入面。
4. 喺 Container Manager，**專案 > 新增**，選擇 compose 檔案。

**Volume：** 媒體路徑用你嘅 Synology 共享資料夾路徑：
```
MEDIA_DIR=/volume1/media/anime
```

<Callout type="warn">
容器預設以 root 身份運行。確保共享資料夾嘅權限容許容器讀取你嘅動畫目錄。
</Callout>

## Unraid

1. 從 Community Applications 安裝 **Docker Compose Manager** 插件。
2. 新增一個 stack，指向 `docker-compose.yml`，並將 `.env` 同 `api/.env` 放喺同一位置。

**Volume：** 用 Unraid 嘅 `/mnt/user/` 慣例：
```
DATA_DIR=/mnt/user/appdata/milmil
MEDIA_DIR=/mnt/user/media/anime
DOWNLOAD_DIR=/mnt/user/downloads/milmil
```

<Callout type="info">
`/mnt/user/appdata/milmil` 係 Unraid 存放持久化應用資料嘅標準路徑。
</Callout>

## TrueNAS SCALE

1. 喺 TrueNAS Web UI：**Apps > Discover Apps > Custom App**。
2. 用 milmil compose 檔案設定 Docker Compose 部署。

**Volume：** 映射你嘅 dataset 路徑：
```
DATA_DIR=/mnt/pool/apps/milmil
MEDIA_DIR=/mnt/pool/media/anime
```

<Callout type="warn">
TrueNAS SCALE 用 Kubernetes 管理自訂應用。確認儲存池權限容許容器讀取媒體 dataset。
</Callout>

## Raspberry Pi（4/5）

<Callout type="warn">
Pi 嘅 CPU 轉碼能力有限。直接播放同容器重新封裝表現唔錯；HLS 轉碼會好慢。建議用預先編碼嘅 MP4 檔案。
</Callout>

1. 安裝 Docker：
   ```bash
   curl -fsSL https://get.docker.com | sh
   sudo usermod -aG docker $USER
   ```
   登出再重新登入。

2. 跟標準 [安裝](/docs/getting-started/installation) 流程操作。

<Callout type="info">
`DATA_DIR` Volume 建議用 USB 3.0 接駁嘅 SSD。SD 卡寫入壽命有限，做資料庫操作亦比較慢。
</Callout>
