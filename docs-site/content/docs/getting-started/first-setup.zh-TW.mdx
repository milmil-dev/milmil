title: 首次設定
description: 安裝完成後——註冊帳號，然後新增並掃描您的第一個媒體庫。
---

milmil 啟動後，您需要完成三個簡短步驟才能開始觀看：在註冊精靈中建立管理員帳號，然後從主介面新增並掃描第一個媒體庫。只有第一個步驟是引導式精靈，後續兩個步驟都是媒體庫區段中的日常操作。

<Steps>

<Step>
### 建立管理員帳號

第一次開啟 milmil 時，應用程式會自動導向 **`/setup`** 頁面，這是一個單頁面的註冊精靈。

輸入使用者名稱與強式密碼後送出。milmil 將建立管理員帳號並直接登入。目前僅支援一個管理員帳號，其他使用者可於日後從設定中建立。

<Callout type="warn">
請設定強式密碼。若無資料庫存取權限，將無法進行密碼復原。
</Callout>

<Callout type="info">
**略過介面：** 您可以透過環境變數自動建立管理員帳號。在首次啟動前，於 `api/.env` 中設定 `ADMIN_USER` 與 `ADMIN_PASSWORD`。若使用者資料表為空，milmil 將於啟動時自動建立管理員帳號，精靈接著會直接跳轉至登入頁面。首次啟動後請刪除這兩個變數，以免密碼留存於磁碟上。
</Callout>
</Step>

<Step>
### 新增第一個媒體庫

註冊完成後，您將進入首頁。此步驟沒有引導式精靈，需手動新增媒體庫：

1. 從側邊欄開啟 **媒體庫**。
2. 點擊 **新增媒體庫**。
3. 填寫表單（儲存後端 + 路徑或連線資訊）並儲存。

milmil 支援多種儲存後端：

<Tabs items={["本機", "網路儲存", "雲端（Rclone）"]}>
<Tab value="本機">
最簡單的設定方式——提供動畫資料夾的路徑：

```
/media/anime
```

<Callout type="info">
若使用 Docker，此路徑必須與容器掛載卷對應（例如，若 `.env` 中的 `MEDIA_DIR` 指向主機上的動畫資料夾，則容器內路徑為 `/media/anime`）。
</Callout>
</Tab>
<Tab value="網路儲存">
對於 SMB、SFTP 或 WebDAV，請在媒體庫表單中填寫連線資訊。支援的通訊協定：

| 類型 | 範例 |
|------|---------|
| **SMB/CIFS** | `\\server\anime` |
| **SFTP** | `sftp://user@host/path` |
| **WebDAV** | `https://cloud.example.com/dav/anime` |
| **FTP** | `ftp://host/anime` |

憑證使用 AES-256 加密儲存。
</Tab>
<Tab value="雲端（Rclone）">
milmil 透過 rclone 整合支援 40 多種雲端服務供應商：Google Drive、OneDrive、Dropbox、S3 等。

請先設定您的 rclone 遠端，再於 milmil 中將其新增為媒體庫來源。
</Tab>
</Tabs>
</Step>

<Step>
### 掃描媒體庫

新建立的媒體庫不會在儲存後立即自動掃描。若要觸發首次掃描：

1. 開啟 **媒體庫** 頁面。
2. 點擊剛新增的媒體庫。
3. 點擊 **掃描**。

（或等待已設定的自動掃描排程觸發。）

掃描流程：

1. 遍歷目錄樹以找出媒體檔案
2. 使用 FFmpeg 擷取中繼資料（編碼格式、解析度、時長、字幕）
3. 透過 DandanPlay、Bangumi 及 AniList 將檔案比對至動畫條目
4. 以封面圖片、標題和簡介豐富集數資訊

<Callout type="info">
大型媒體庫的初次掃描可能需要數分鐘。進度會顯示於介面上。
</Callout>
</Step>

</Steps>

## 中繼資料比對

milmil 使用多重供應商的比對流程：

1. **DandanPlay 雜湊** — 最精確，依檔案雜湊值比對
2. **Bangumi** — 依標題比對 Bangumi 資料庫
3. **AniList** — 替代標題比對
4. **TMDB** — 備援交叉參照

未比對的檔案可於媒體庫詳情頁面手動比對。
