<Callout type="info">
请先参照标准[安装](/docs/getting-started/installation)指南完成安装。本页仅记录各平台的差异部分。
</Callout>

## Synology NAS (DSM 7+)

1. 从套件中心安装 **Container Manager**。
2. 通过 SSH 登录并创建 `/volume1/docker/milmil/` 目录。
3. 将项目中的 `docker-compose.yml`、`.env` 和 `api/.env` 复制到该目录。
4. 在 Container Manager 中，选择**项目 > 新建**，选择 compose 文件。

**卷挂载：** 使用 Synology 共享文件夹路径作为媒体目录：
```
MEDIA_DIR=/volume1/media/anime
```

<Callout type="warn">
容器默认以 root 用户运行。请确保共享文件夹权限允许容器读取你的动画媒体库目录。
</Callout>

## Unraid

1. 从社区应用商店安装 **Docker Compose Manager** 插件。
2. 添加新堆栈，指向 `docker-compose.yml`，并将 `.env` 和 `api/.env` 置于同一目录。

**卷挂载：** 使用 Unraid 的 `/mnt/user/` 路径规范：
```
DATA_DIR=/mnt/user/appdata/milmil
MEDIA_DIR=/mnt/user/media/anime
DOWNLOAD_DIR=/mnt/user/downloads/milmil
```

<Callout type="info">
`/mnt/user/appdata/milmil` 是 Unraid 持久化应用数据的标准路径。
</Callout>

## TrueNAS SCALE

1. 在 TrueNAS Web UI 中：**应用 > 发现应用 > 自定义应用**。
2. 使用 milmil compose 文件配置 Docker Compose 部署。

**卷挂载：** 映射你的数据集路径：
```
DATA_DIR=/mnt/pool/apps/milmil
MEDIA_DIR=/mnt/pool/media/anime
```

<Callout type="warn">
TrueNAS SCALE 的自定义应用使用 Kubernetes。请确认存储池权限允许容器读取媒体数据集。
</Callout>

## 树莓派（4/5）

<Callout type="warn">
树莓派的 CPU 转码能力有限。直接播放和容器重封装效果良好；HLS 转码较慢。建议优先使用预编码的 MP4 文件。
</Callout>

1. 安装 Docker：
   ```bash
   curl -fsSL https://get.docker.com | sh
   sudo usermod -aG docker $USER
   ```
   注销并重新登录。

2. 按照标准[安装](/docs/getting-started/installation)流程继续操作。

<Callout type="info">
建议使用通过 USB 3.0 连接的 SSD 作为 `DATA_DIR` 卷。SD 卡写入寿命有限，数据库操作速度也较慢。
</Callout>
