## 設定精靈

第一次開啟 milmil 嘅時候，你會進入設定精靈：

1. **建立管理員帳號** — 設定使用者名稱同密碼
2. **新增媒體庫** — 指定你嘅動畫媒體目錄
3. **掃描媒體庫** — milmil 自動掃描並比對你嘅檔案

## 新增媒體庫

milmil 支援多種儲存後端：

| 類型 | 說明 |
|------|-------------|
| **本機** | 主機檔案系統上嘅目錄 |
| **SMB/CIFS** | Windows 網路共享 |
| **SFTP** | SSH 檔案傳輸 |
| **WebDAV** | 雲端儲存（Nextcloud 等） |
| **Rclone** | 40+ 雲端服務提供商（Google Drive、OneDrive、Dropbox、S3 等） |

### 本機目錄

最簡單嘅設定方式 — 只需提供你嘅動畫資料夾路徑：

```
/media/anime
```

### 網路儲存

對於 SMB、SFTP 或 WebDAV，喺媒體庫設定入面提供連線資訊。憑證用 AES-256 加密儲存。

## 中繼資料比對

掃描完成之後，milmil 會自動將檔案比對到動畫條目：

1. **DandanPlay** — 檔案雜湊比對（最精確）
2. **Bangumi** — 基於標題嘅比對
3. **AniList** — 替代中繼資料來源

未比對嘅檔案可以喺媒體庫詳情頁手動比對。
