---
title: 首次設定
description: 裝好之後 — 注冊帳號，再添加同掃描你嘅第一個媒體庫。
---

milmil 跑起來之後，要做三件短事先可以開始睇嘢：喺注冊嚮導建立管理員帳號，然後喺主介面添加同掃描第一個媒體庫。只有第一件事係有嚮導引導嘅 — 後兩件係媒體庫部分嘅日常操作。

<Steps>

<Step>
### 建立管理員帳號

第一次打開 milmil，應用程式會自動跳去 **`/setup`** 頁面。係一個單頁注冊嚮導。

輸入用戶名同一個夠強嘅密碼，然後提交。milmil 會建立管理員帳號並直接幫你登入。目前只有一個管理員帳號 — 之後可以喺設定入面建立額外用戶。

<Callout type="warn">
揀個夠強嘅密碼。冇資料庫存取權限嘅話係冇辦法重設密碼嘅。
</Callout>

<Callout type="info">
**跳過 UI：** 可以透過環境變數自動預建管理員帳號。喺第一次啟動前，喺 `api/.env` 設好 `ADMIN_USER` 同 `ADMIN_PASSWORD`。如果用戶資料表係空嘅，milmil 啟動時會自動建立管理員，然後嚮導直接跳去登入頁。第一次啟動後記得刪走呢兩個變數，唔好將密碼留喺磁碟上。
</Callout>
</Step>

<Step>
### 添加第一個媒體庫

注冊後你會去到主頁。呢個步驟冇應用內嚮導 — 要手動添加媒體庫：

1. 喺側邊欄打開 **媒體庫**。
2. 撳 **添加媒體庫**。
3. 填好表單（儲存後端 + 路徑或連線資料）然後儲存。

milmil 支援多種儲存後端：

<Tabs items={["本地", "網絡儲存", "雲端 (Rclone)"]}>
<Tab value="本地">
最簡單嘅設定 — 提供你嘅動畫資料夾路徑就得：

```
/media/anime
```

<Callout type="info">
如果用緊 Docker，呢個路徑要同容器 Volume 掛載一致（例如 `/media/anime`，前提係你 `.env` 入面嘅 `MEDIA_DIR` 指向主機上嘅動畫資料夾）。
</Callout>
</Tab>
<Tab value="網絡儲存">
SMB、SFTP 或 WebDAV 嘅話，喺媒體庫表單入面填好連線資料。支援嘅協議：

| 類型 | 範例 |
|------|---------|
| **SMB/CIFS** | `\\server\anime` |
| **SFTP** | `sftp://user@host/path` |
| **WebDAV** | `https://cloud.example.com/dav/anime` |
| **FTP** | `ftp://host/anime` |

憑證用 AES-256 加密儲存。
</Tab>
<Tab value="雲端 (Rclone)">
milmil 透過 rclone 整合支援 40+ 種雲端提供商：Google Drive、OneDrive、Dropbox、S3 等等。

先設定好你嘅 rclone remote，然後喺 milmil 入面將佢添加為媒體庫來源。
</Tab>
</Tabs>
</Step>

<Step>
### 掃描媒體庫

新媒體庫唔會喺你儲存之後自動掃描。要觸發第一次掃描：

1. 打開 **媒體庫** 頁面。
2. 撳入你剛剛添加嘅媒體庫。
3. 撳 **掃描**。

（或者等設定好嘅自動掃描間隔自己觸發。）

掃描流程：

1. 遍歷目錄樹搵出媒體檔案
2. 用 FFmpeg 抽取媒體資料（編碼、解析度、片長、字幕）
3. 用 DandanPlay、Bangumi 同 AniList 將檔案比對到動畫條目
4. 補齊集數嘅封面圖、標題同簡介

<Callout type="info">
大型媒體庫第一次掃描可能需要幾分鐘。進度會喺介面顯示。
</Callout>
</Step>

</Steps>

## 中繼資料比對

milmil 用多提供商比對流程：

1. **DandanPlay 哈希** — 最精確，以檔案哈希比對
2. **Bangumi** — 對照 Bangumi 資料庫做標題比對
3. **AniList** — 備用標題比對
4. **TMDB** — 退回交叉參考

未比對到嘅檔案可以喺媒體庫詳情頁手動比對。
