---
title: First-time Setup
description: After installation — signup, then add and scan your first library.
---

Once milmil is running, you'll work through three short tasks to start watching: create your admin account in the signup wizard, then add and scan your first library from the main UI. Only the first task is a guided wizard — the next two are everyday actions in the Libraries section.

<Steps>

<Step>
### Create your admin account

The first time you open milmil, the app routes you to the **`/setup`** page. It's a one-screen signup wizard.

Enter a username and a strong password and submit. milmil creates the admin user and logs you straight in. There is currently only one admin account — additional users can be created later from settings.

<Callout type="warn">
Choose a strong password. There is no password recovery without database access.
</Callout>

<Callout type="info">
**Skip the UI:** You can auto-provision the admin account via env vars. Set `ADMIN_USER` and `ADMIN_PASSWORD` in `api/.env` before first boot. milmil creates the admin on startup if the users table is empty, then the wizard redirects straight to login. Remove the vars after first boot to avoid leaving the password on disk.
</Callout>
</Step>

<Step>
### Add your first library

After signup you land on the home page. There is no in-app wizard for this step — you add libraries manually:

1. Open **Libraries** from the sidebar.
2. Click **Add Library**.
3. Fill in the form (storage backend + path or connection details) and save.

milmil supports multiple storage backends:

<Tabs items={["Local", "Network Storage", "Cloud (Rclone)"]}>
<Tab value="Local">
The simplest setup — provide the path to your anime folder:

```
/media/anime
```

<Callout type="info">
If using Docker, this path must match your container volume mount (e.g. `/media/anime` if your `MEDIA_DIR` in `.env` points to your anime folder on the host).
</Callout>
</Tab>
<Tab value="Network Storage">
For SMB, SFTP, or WebDAV, provide the connection details in the library form. Supported protocols:

| Type | Example |
|------|---------|
| **SMB/CIFS** | `\\server\anime` |
| **SFTP** | `sftp://user@host/path` |
| **WebDAV** | `https://cloud.example.com/dav/anime` |
| **FTP** | `ftp://host/anime` |

Credentials are encrypted with AES-256.
</Tab>
<Tab value="Cloud (Rclone)">
milmil supports 40+ cloud providers via rclone integration: Google Drive, OneDrive, Dropbox, S3, and more.

Configure your rclone remote first, then add it as a library source in milmil.
</Tab>
</Tabs>
</Step>

<Step>
### Scan the library

A new library doesn't scan automatically the moment you save it. To trigger the first scan:

1. Open the **Libraries** page.
2. Click into the library you just added.
3. Click **Scan**.

(Or wait for the configured auto-scan interval to fire.)

The scan pipeline:

1. Walks the directory tree to discover media files
2. Extracts metadata using FFmpeg (codec, resolution, duration, subtitles)
3. Matches files to anime entries using DandanPlay, Bangumi, and AniList
4. Enriches episodes with cover images, titles, and descriptions

<Callout type="info">
Initial scans can take several minutes for large libraries. Progress is shown in the UI.
</Callout>
</Step>

</Steps>

## Metadata Matching

milmil uses a multi-provider matching pipeline:

1. **DandanPlay Hash** — Most accurate, matches by file hash
2. **Bangumi** — Title-based matching against the Bangumi database
3. **AniList** — Alternative title matching
4. **TMDB** — Fallback cross-reference

Unmatched files can be manually matched from the library detail page.
