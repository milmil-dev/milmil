---
title: 平台專屬說明
description: Synology、Unraid、TrueNAS 與 Raspberry Pi 相較於標準 Docker Compose 安裝的差異說明。
---

<Callout type="info">
請先依照標準[安裝](/docs/getting-started/installation)指南操作。本頁僅說明各平台上的差異之處。
</Callout>

## Synology NAS（DSM 7+）

1. 從套件中心安裝 **Container Manager**。
2. 透過 SSH 登入並建立 `/volume1/docker/milmil/`。
3. 將專案的 `docker-compose.yml`、`.env` 及 `api/.env` 複製至該資料夾。
4. 在 Container Manager 中，點擊 **專案 > 新增**，選取 compose 檔案。

**掛載卷：** 請使用您的 Synology 共用資料夾路徑作為媒體來源：
```
MEDIA_DIR=/volume1/media/anime
```

<Callout type="warn">
容器預設以 root 身份執行。請確認共用資料夾的權限允許容器讀取您的動畫目錄。
</Callout>

## Unraid

1. 從 Community Applications 安裝 **Docker Compose Manager** 插件。
2. 新增一個 stack，指向 `docker-compose.yml`，並將 `.env` 及 `api/.env` 放在同一目錄下。

**掛載卷：** 請使用 Unraid 的 `/mnt/user/` 路徑慣例：
```
DATA_DIR=/mnt/user/appdata/milmil
MEDIA_DIR=/mnt/user/media/anime
DOWNLOAD_DIR=/mnt/user/downloads/milmil
```

<Callout type="info">
`/mnt/user/appdata/milmil` 是 Unraid 上持久化應用程式資料的標準路徑。
</Callout>

## TrueNAS SCALE

1. 在 TrueNAS 網頁介面中：**應用程式 > 探索應用程式 > 自訂應用程式**。
2. 使用 milmil 的 compose 檔案設定 Docker Compose 部署。

**掛載卷：** 對應您的資料集路徑：
```
DATA_DIR=/mnt/pool/apps/milmil
MEDIA_DIR=/mnt/pool/media/anime
```

<Callout type="warn">
TrueNAS SCALE 底層使用 Kubernetes 管理自訂應用程式。請確認儲存池的權限允許容器讀取媒體資料集。
</Callout>

## Raspberry Pi（4/5）

<Callout type="warn">
Pi 的 CPU 轉碼能力有限。直接播放與容器重新封裝表現良好；HLS 轉碼速度較慢。建議優先使用預先編碼的 MP4 檔案。
</Callout>

1. 安裝 Docker：
   ```bash
   curl -fsSL https://get.docker.com | sh
   sudo usermod -aG docker $USER
   ```
   登出後重新登入。

2. 依照標準[安裝](/docs/getting-started/installation)流程操作。

<Callout type="info">
建議透過 USB 3.0 連接 SSD 作為 `DATA_DIR` 掛載卷。SD 卡的寫入壽命有限，且資料庫操作速度較慢。
</Callout>
