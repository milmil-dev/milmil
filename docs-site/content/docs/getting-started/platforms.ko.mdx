## Synology NAS (DSM 7+)

<Steps>
<Step>
### Container Manager 설치

**패키지 센터**를 열고 **Container Manager** (이전 명칭: Docker)를 설치하세요.
</Step>
<Step>
### 프로젝트 디렉토리 생성

NAS에 SSH로 접속하거나 File Station을 사용하여 `/docker/milmil/`을 생성하세요.

<Files>
  <Folder name="docker" defaultOpen>
    <Folder name="milmil" defaultOpen>
      <File name=".env" />
      <File name="docker-compose.yml" />
      <Folder name="data" />
    </Folder>
  </Folder>
</Files>
</Step>
<Step>
### docker-compose.yml 및 .env 업로드

프로덕션 compose 파일과 환경 변수를 복사하세요. [Docker 배포](/docs/getting-started/docker)를 참조하세요.
</Step>
<Step>
### Container Manager에서 시작

Container Manager에서 **프로젝트 > 만들기**로 이동하세요. `docker-compose.yml` 파일을 선택하고 프로젝트를 시작하세요.
</Step>
</Steps>

<Callout type="warn">
**권한:** Synology 컨테이너는 기본적으로 root로 실행됩니다. 공유 폴더 권한이 애니메이션 라이브러리 디렉토리에 대한 읽기 접근을 허용하는지 확인하세요. 볼륨 마운트를 공유 폴더 경로(예: `/volume1/media/anime`)로 설정하세요.
</Callout>

</Tab>

## Unraid

<Steps>
<Step>
### Docker Compose Manager 설치

Unraid **Community Applications** 스토어에서 **Docker Compose Manager** 플러그인을 설치하세요.
</Step>
<Step>
### Compose 스택 생성

milmil의 `docker-compose.yml`과 `.env` 파일로 새 스택을 추가하세요. [Docker 배포](/docs/getting-started/docker)를 참조하세요.
</Step>
<Step>
### 경로 설정

미디어 공유를 매핑하세요:

```yaml
volumes:
  - /mnt/user/media/anime:/media/anime
  - /mnt/user/appdata/milmil:/data
```
</Step>
<Step>
### 스택 시작

Docker Compose Manager UI에서 compose 스택을 적용하세요.
</Step>
</Steps>

<Callout type="info">
Unraid 규칙에 따라 영구 데이터에는 `/mnt/user/appdata/milmil`을 사용하세요.
</Callout>

## TrueNAS SCALE

<Steps>
<Step>
### 앱으로 이동

TrueNAS SCALE 웹 UI에서 **앱 > 앱 검색**으로 이동하세요.
</Step>
<Step>
### 커스텀 앱

**커스텀 앱**을 클릭하고 milmil compose 파일로 Docker Compose 배포를 설정하세요.
</Step>
<Step>
### 스토리지 설정

데이터셋 경로를 매핑하세요:

```yaml
volumes:
  - /mnt/pool/media/anime:/media/anime
  - /mnt/pool/apps/milmil:/data
```
</Step>
</Steps>

<Callout type="warn">
TrueNAS SCALE는 커스텀 앱에 대해 내부적으로 Kubernetes를 사용합니다. 풀 경로가 올바르고 접근 가능한지 확인하세요.
</Callout>

## Raspberry Pi (4/5)

<Callout type="warn">
Raspberry Pi는 트랜스코딩을 위한 CPU가 제한적입니다. 다이렉트 플레이와 컨테이너 리먹싱은 잘 작동하지만, HLS 트랜스코딩은 느릴 수 있습니다. 최상의 결과를 위해 사전 인코딩된 MP4 파일을 사용하세요.
</Callout>

<Steps>
<Step>
### Docker 설치

```bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
```

그룹 변경 사항을 적용하려면 로그아웃 후 다시 로그인하세요.
</Step>
<Step>
### 클론 및 시작

```bash
git clone https://github.com/milmil-dev/milmil.git
cd milmil
docker compose up -d
```
</Step>
</Steps>

<Callout type="info">
데이터 볼륨에는 SD 카드 대신 SSD(USB 3.0 연결)를 사용하세요 — SD 카드는 쓰기 수명이 제한적이며 데이터베이스 작업이 느립니다.
</Callout>
