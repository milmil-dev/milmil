## 设置向导

首次打开 milmil 时，你将进入设置向导：

1. **创建管理员账户** — 设置用户名和密码
2. **添加媒体库** — 指定你的动画媒体目录
3. **扫描媒体库** — milmil 自动扫描并匹配你的文件

## 添加媒体库

milmil 支持多种存储后端：

| 类型 | 说明 |
|------|-------------|
| **本地** | 主机文件系统上的目录 |
| **SMB/CIFS** | Windows 网络共享 |
| **SFTP** | SSH 文件传输 |
| **WebDAV** | 云存储（Nextcloud 等） |
| **Rclone** | 40+ 云服务提供商（Google Drive、OneDrive、Dropbox、S3 等） |

### 本地目录

最简单的设置方式 — 只需提供你的动画文件夹路径：

```
/media/anime
```

### 网络存储

对于 SMB、SFTP 或 WebDAV，在媒体库设置中提供连接信息。凭据使用 AES-256 加密存储。

## 元数据匹配

扫描完成后，milmil 会自动将文件匹配到动画条目：

1. **DandanPlay** — 文件哈希匹配（最精确）
2. **Bangumi** — 基于标题的匹配
3. **AniList** — 备选元数据来源

未匹配的文件可以在媒体库详情页手动匹配。
