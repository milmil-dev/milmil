## 设置向导

首次打开 milmil 时，你将进入设置向导：

<Steps>
<Step>
### 创建管理员账户

设置用户名和密码。此为唯一的管理员账户 — 之后可另行创建普通用户。

<Callout type="warn">
请设置强密码。在没有数据库访问权限的情况下，无法找回密码。
</Callout>

<Callout type="info">
**跳过 UI：** 你可通过环境变量自动配置管理员账户。在首次启动前，在 `api/.env` 中设置 `ADMIN_USER` 和 `ADMIN_PASSWORD`。若用户表为空，milmil 将在启动时自动创建管理员账户，向导随后会直接跳转到登录页。首次启动后请删除这两个变量，以免密码明文遗留在磁盘上。
</Callout>
</Step>
<Step>
### 添加媒体库

指定你的动画媒体目录。milmil 支持多种存储后端：

<Tabs items={["本地", "网络存储", "云端（Rclone）"]}>
<Tab value="本地">
最简单的方式 — 提供动画文件夹的路径：

```
/media/anime
```

<Callout type="info">
如果使用 Docker，此路径须与容器卷挂载一致（例如，若挂载为 `-v /path/to/anime:/media/anime`，则填写 `/media/anime`）。
</Callout>
</Tab>
<Tab value="网络存储">
对于 SMB、SFTP 或 WebDAV，在媒体库设置中提供连接信息。支持的协议：

| 类型 | 示例 |
|------|---------|
| **SMB/CIFS** | `\\server\anime` |
| **SFTP** | `sftp://user@host/path` |
| **WebDAV** | `https://cloud.example.com/dav/anime` |
| **FTP** | `ftp://host/anime` |

凭据使用 AES-256 加密存储。
</Tab>
<Tab value="云端（Rclone）">
milmil 通过 rclone 集成支持 40+ 云服务提供商：Google Drive、OneDrive、Dropbox、S3 等。

先配置好 rclone 远程端，再在 milmil 中将其添加为媒体库来源。
</Tab>
</Tabs>
</Step>
<Step>
### 扫描媒体库

milmil 自动扫描并匹配你的文件。扫描流程：

1. 遍历目录树，发现媒体文件
2. 使用 FFmpeg 提取元数据（编码格式、分辨率、时长、字幕）
3. 通过 DandanPlay、Bangumi 和 AniList 将文件匹配到动画条目
4. 用封面图、标题和简介丰富剧集信息

<Callout type="info">
大型媒体库的首次扫描可能需要数分钟。进度会在 UI 中实时显示。
</Callout>
</Step>
</Steps>

## 元数据匹配

milmil 使用多提供商匹配流水线：

1. **DandanPlay 哈希** — 最精确，通过文件哈希匹配
2. **Bangumi** — 基于 Bangumi 数据库的标题匹配
3. **AniList** — 备选标题匹配
4. **TMDB** — 兜底交叉参照

未匹配的文件可在媒体库详情页手动匹配。
