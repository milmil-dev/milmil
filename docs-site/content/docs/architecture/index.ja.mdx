## システム概要

milmil は、セルフホストデプロイ向けに設計された Go モノリシックバックエンドと React SPA フロントエンドで構成されています。

```
┌─────────────────────────────────────────────────┐
│                   クライアント                    │
│         ブラウザ (PWA)  │  Telegram/Discord Bot  │
└───────────┬─────────────────────┬───────────────┘
            │ HTTP/WS             │ Bot API
┌───────────▼─────────────────────▼───────────────┐
│                milmil-api (Go)                  │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐│
│  │ REST API │ │WebSocket │ │ Bot Engine       ││
│  └────┬─────┘ └────┬─────┘ └───────┬──────────┘│
│       │             │               │           │
│  ┌────▼─────────────▼───────────────▼──────────┐│
│  │              サービス層                      ││
│  │  Library │ Stream │ Download │ Discover     ││
│  │  Collection │ Auth │ Notification           ││
│  └────┬────────────────────────────────────────┘│
│       │                                         │
│  ┌────▼────────────────────────────────────────┐│
│  │           インフラ層                         ││
│  │  PostgreSQL/SQLite │ Redis │ FFmpeg │ Rclone││
│  └─────────────────────────────────────────────┘│
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│              milmil-web (React SPA)             │
│  Nginx またはデブサーバー経由で配信              │
└─────────────────────────────────────────────────┘
```

## コンポーネント概要

| コンポーネント | 説明 |
|---|---|
| **REST API** | Echo ルーターで JSON エンドポイントを提供。認証、CRUD、ストリーミング、検索を処理。 |
| **WebSocket** | 弾幕、通知、スキャン進捗のリアルタイムイベントプッシュ。 |
| **Bot Engine** | Telegram と Discord のアダプターを備えたプラットフォーム非依存ボット。 |
| **サービス層** | ライブラリスキャン、メタデータマッチング、ダウンロード管理、コレクション同期のビジネスロジック。 |
| **FFmpeg** | メディアプロービング、コンテナリミックス、HLS トランスコーディング。 |
| **Rclone** | 40 以上のプロバイダーに対応したクラウドストレージ抽象化。 |

## データフロー：ライブラリスキャン

<Steps>
<Step>
### ファイル検出

ストレージバックエンド（ローカル、SMB、rclone など）を走査して、すべてのメディアファイルを列挙します。
</Step>
<Step>
### メディアプロービング

FFmpeg で各ファイルのコーデック情報、解像度、再生時間、埋め込み字幕、オーディオトラックを解析します。
</Step>
<Step>
### メタデータマッチング

プロバイダーパイプラインを使用してファイルをアニメエントリにマッチング：DandanPlay（ハッシュ）→ Bangumi（タイトル）→ AniList（タイトル）→ TMDB（フォールバック）。
</Step>
<Step>
### エンリッチメント

マッチしたプロバイダーからカバー画像、エピソードタイトル、あらすじ、評価を取得します。
</Step>
<Step>
### 永続化

すべてのメタデータをデータベースに保存。スキャン完了通知を送信します。
</Step>
</Steps>

## テクノロジースタック

| テクノロジー | 説明 |
|---|---|
| **バックエンド** | Go — Chi ルーター、sqlc、golang-migrate、anacrolix/torrent |
| **フロントエンド** | React — Vite、TanStack Router、TanStack Query、Tailwind CSS |
| **データベース** | PostgreSQL/SQLite — golang-migrate でスキーマ管理 |
| **キャッシュ** | Redis — オプション、インメモリフォールバック利用可能 |
| **メディア** | FFmpeg — プロービング、リミックス、HLS トランスコーディング |
| **ストレージ** | Rclone — 40 以上のクラウドプロバイダーバックエンド |
| **ドキュメント** | Fumadocs — i18n 対応の Next.js ベースドキュメント |
