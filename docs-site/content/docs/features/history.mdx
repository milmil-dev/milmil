## Overview

milmil automatically records every episode you watch, including timestamps and playback progress. The history page gives you a searchable, filterable view of everything you have watched.

## Browsing History

Episodes appear in a grid layout showing:

- Episode thumbnail with overlay progress bar
- Anime title and episode number
- Last watched timestamp
- Completion status

The grid uses **infinite scroll** pagination — older entries load automatically as you scroll down.

## Filtering and Search

Use the filter bar to narrow your history:

| Filter | Description |
|--------|-------------|
| **All** | Every watched episode |
| **Watching** | Anime you are currently watching |
| **Completed** | Anime you have finished |
| **Dropped** | Anime you stopped watching |

You can also search by anime title to quickly find a specific series.

<Callout type="info">
Filters and search work together — combine a status filter with a title search to find exactly what you need.
</Callout>

## Batch Operations

Toggle **batch mode** to select multiple history entries at once.

<Steps>
<Step>
### Enable batch mode

Click the batch mode toggle in the toolbar to enter multi-select mode.
</Step>
<Step>
### Select entries

Click individual entries to select them, or use select-all to grab everything visible.
</Step>
<Step>
### Apply action

Choose an action — **clear selected** resets progress for the selected entries, or **delete** removes them from your history entirely.
</Step>
</Steps>

<Callout type="warn">
Deleting history entries is permanent and cannot be undone.
</Callout>
