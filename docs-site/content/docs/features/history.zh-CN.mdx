## 概览

milmil 会自动记录你观看的每一集，包括时间戳和播放进度。历史页面提供可搜索、可筛选的完整观看记录。

## 浏览历史

剧集以网格布局展示，包含：

- 带进度条叠加层的剧集缩略图
- 动画标题和集数
- 最后观看时间
- 完成状态

网格使用**无限滚动**分页 — 向下滚动时自动加载更早的记录。

## 筛选与搜索

使用筛选栏缩小历史范围：

| 筛选条件 | 说明 |
|--------|-------------|
| **全部** | 所有已观看的剧集 |
| **在看** | 当前正在观看的动画 |
| **已完成** | 已看完的动画 |
| **已弃** | 已停止观看的动画 |

你也可以通过动画标题搜索来快速定位特定系列。

<Callout type="info">
筛选和搜索可以配合使用 — 将状态筛选与标题搜索组合，精准找到你需要的内容。
</Callout>

## 批量操作

切换**批量模式**以一次选择多条历史记录。

<Steps>
<Step>
### 启用批量模式

点击工具栏中的批量模式开关，进入多选模式。
</Step>
<Step>
### 选择记录

点击单条记录进行选择，或使用全选来选中所有可见记录。
</Step>
<Step>
### 执行操作

选择操作 — **清除所选**会重置所选记录的进度，**删除**则会将其从历史中彻底移除。
</Step>
</Steps>

<Callout type="warn">
删除历史记录是永久性的，无法撤销。
</Callout>
