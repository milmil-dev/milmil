## 概览

弹幕在视频播放过程中滚动显示，重现 Bilibili 和 Niconico 等平台上的共同观看体验。milmil 集成了 [弹弹play开放弹幕网络（DandanPlay）](https://www.dandanplay.com/) 弹幕数据库，可为每集拉取数千条时间同步的弹幕。

<Callout type="info">
弹幕功能需要 DandanPlay 连接。请参阅[集成设置](/docs/configuration/integrations)进行配置。
</Callout>

## 弹幕来源

milmil 会将剧集匹配到多个弹幕数据库：

- **弹弹play开放弹幕网络（DandanPlay）** — 主要来源，拥有最大的中文弹幕库
- **外部数据库** — DandanPlay 聚合的其他来源

使用播放器中的**来源标签页**浏览可用剧集并选择要加载的弹幕集。当自动匹配选错剧集或你想要不同版本的弹幕时，此功能非常有用。

## 设置

从播放器设置面板精调弹幕显示效果：

| 设置项 | 说明 |
| --- | --- |
| **不透明度** | 弹幕透明度（0 &ndash; 100%） |
| **字体大小** | 相对于视频的文字大小 |
| **速度** | 弹幕在屏幕上滚动的速度 |
| **显示区域** | 视频被弹幕覆盖的区域（上半部分、全屏、底部） |
| **密度** | 同时在屏幕上显示的最大弹幕数量 |

## 筛选与搜索

**弹幕列表**面板按时间顺序显示所有已加载的弹幕。你可以：

- 按关键词搜索弹幕
- 按弹幕类型筛选（滚动、顶部固定、底部固定）
- 跳转到特定弹幕的时间点

## 开关

使用播放器控制栏中的弹幕按钮随时显示或隐藏弹幕。你的偏好会在会话间保留。
