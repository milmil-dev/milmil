## 概覽

milmil 的媒體庫系統讓你從多個儲存後端組織和管理動畫檔案。檔案會被自動掃描、識別，並使用來自 Bangumi、AniList 和 DandanPlay 的中繼資料比對到動畫條目。

## 儲存後端

| 後端 | 說明 |
|---------|-------------|
| **本機** | 主機檔案系統上的目錄 |
| **SMB/CIFS** | Windows 網路共享 |
| **SFTP** | SSH 檔案傳輸 |
| **FTP** | 標準 FTP |
| **WebDAV** | 雲端儲存（Nextcloud 等） |
| **HTTP** | 直接 HTTP 檔案存取 |
| **Rclone** | 40+ 雲端服務提供商（Google Drive、OneDrive、Dropbox、S3 等） |

## 掃描

掃描媒體庫時，milmil 會：

1. 遍歷目錄樹發現媒體檔案
2. 使用 FFmpeg 擷取中繼資料（編解碼器、解析度、時長、字幕）
3. 使用多個提供商將檔案比對到動畫條目
4. 為劇集補充封面圖片、標題和簡介

掃描可以手動觸發，也可以設定為自動執行。

## 中繼資料比對

milmil 使用多提供商比對管線：

1. **DandanPlay 雜湊** — 最精確，透過檔案雜湊比對
2. **Bangumi** — 基於標題的比對，對照 Bangumi 資料庫
3. **AniList** — 替代標題比對
4. **TMDB** — 備援交叉參照

未比對的檔案可以在媒體庫詳情頁手動比對。

## 檔案瀏覽器

媒體庫詳情頁包含一個檔案瀏覽器，顯示：

- 目錄樹及檔案數量
- 媒體檔案詳情（編解碼器、解析度、大小）
- 每個檔案的比對狀態
- 批次比對/取消比對操作
