## Torrent クライアント

milmil には以下の機能を備えた Torrent クライアントが内蔵されています：

- 設定可能なシード率と時間制限
- DHT とピア交換のサポート
- ダウンロード進捗のトラッキング
- 一時停止/再開コントロール

### 設定

| 設定 | デフォルト | 説明 |
|---------|---------|-------------|
| `TORRENT_LISTEN_PORT` | `42069` | DHT/ピアポート |
| `SEED_RATIO` | `1.0` | 目標シード率 |
| `SEED_TIME_MINUTES` | `60` | 最小シード時間 |

## Torrent 検索

単一のインターフェースから複数の Torrent プロバイダーを横断検索：

- **Nyaa** — 最大のアニメ Torrent トラッカー
- **DMHY** — 中国語アニメ Torrent
- **Mikan** — Mikan Project アグリゲーター
- **Bangumi.moe** — Bangumi Torrent トラッカー
- **ACG.rip** — ACG リソーストラッカー

解像度、字幕グループ、ファイルタイプで結果をフィルタリング。

## RSS 自動ダウンロード

RSS フィードを購読してエピソードを自動ダウンロード：

1. RSS フィード URL を追加
2. フィルターを設定（正規表現パターン、解像度、字幕グループの優先順位）
3. milmil が定期的にフィードをチェックし、マッチするエピソードをダウンロード
4. ダウンロードされたファイルは自動的にスキャンされマッチング

### ダウンロード後パイプライン

ダウンロード完了後、milmil は自動的に：

1. ダウンロードされたファイルをスキャン
2. 正しいアニメとエピソードにマッチング
3. プロバイダーからメタデータを補完
4. 通知を送信

## HTTP ダウンロード

milmil はレジューム機能付きのダイレクト HTTP ダウンロードにも対応しています。
