## 개요

milmil은 라이브러리를 체계적으로 관리하기 위한 파일 관리 도구를 제공합니다. 설정 가능한 패턴을 사용하여 파일 이름을 일괄 변경하고, 중복 파일을 감지하여 스토리지 공간을 회수할 수 있습니다.

## 파일 이름 변경

패턴 템플릿을 사용하여 미디어 파일의 이름을 변경하며, 적용 전 실시간 미리보기를 제공합니다.

<Steps>
<Step>
### 파일 선택

라이브러리 상세 페이지에서 파일 이름 변경 도구를 열고 이름을 변경할 파일을 선택합니다.
</Step>
<Step>
### 패턴 구성

사용 가능한 토큰을 활용하여 이름 변경 패턴을 선택합니다. 예: `[SubGroup] Title - E01.mkv`.
</Step>
<Step>
### 미리보기 및 적용

각 파일의 변경 전/후 미리보기를 확인한 다음 이름 변경을 적용합니다.
</Step>
</Steps>

<Callout type="info">
모든 이름 변경 작업은 이름 변경 기록에 추적되므로 언제든지 과거 변경 사항을 확인할 수 있습니다.
</Callout>

## 중복 감지

라이브러리 내 중복 파일을 자동으로 식별하고 일괄 정리합니다.

### 감지 방법

| 방법 | 설명 |
|--------|-------------|
| **파일 해시** | 콘텐츠 해시에 의한 정확한 매칭 (가장 정확) |
| **이름 유사도** | 파일 이름에 대한 퍼지 매칭 |
| **에피소드 매칭** | 동일한 애니메이션 에피소드에 매칭된 파일 |

### 정리 워크플로우

<Steps>
<Step>
### 중복 스캔

라이브러리에서 중복 감지를 실행하여 매칭되는 파일 그룹을 표시합니다.
</Step>
<Step>
### 파일 비교

파일 경로 비교 뷰를 사용하여 어떤 사본을 유지할지 결정합니다.
</Step>
<Step>
### 일괄 정리

여러 그룹에서 중복 파일을 선택하고 한 번의 작업으로 삭제하거나 이동합니다.
</Step>
</Steps>

<Callout type="warn">
삭제된 파일은 영구적으로 제거됩니다. 일괄 삭제를 확인하기 전에 비교 뷰를 반드시 확인하세요.
</Callout>
