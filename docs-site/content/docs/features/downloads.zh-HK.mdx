## 種子用戶端

milmil 內建種子用戶端，支援：

- 可設定嘅做種比率同時間限制
- DHT 同對等交換支援
- 下載進度追蹤
- 暫停/繼續控制

### 設定

| 設定 | 預設值 | 說明 |
|---------|---------|-------------|
| `TORRENT_LISTEN_PORT` | `42069` | DHT/對等連接埠 |
| `SEED_RATIO` | `1.0` | 目標做種比率 |
| `SEED_TIME_MINUTES` | `60` | 最短做種時間 |

## 種子搜尋

喺單一介面入面跨多個種子提供商搜尋：

- **Nyaa** — 最大嘅動畫種子追蹤器
- **DMHY** — 中文動畫種子
- **Mikan** — 蜜柑計劃聚合器
- **Bangumi.moe** — Bangumi 種子追蹤器
- **ACG.rip** — ACG 資源追蹤器

按解析度、字幕組同檔案類型篩選結果。

## RSS 自動下載

訂閱 RSS 來源，自動下載劇集：

1. 新增 RSS 來源 URL
2. 設定篩選器（正規表示式、解析度、字幕組偏好）
3. milmil 定期檢查來源並下載符合嘅劇集
4. 下載嘅檔案自動掃描並比對

### 下載後處理流程

下載搞掂之後，milmil 自動執行：

1. 掃描下載嘅檔案
2. 比對到正確嘅動畫同劇集
3. 從提供商補充中繼資料
4. 傳送通知

## HTTP 下載

milmil 仲支援直接 HTTP 下載，具備斷點續傳功能。
