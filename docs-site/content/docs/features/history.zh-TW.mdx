## 概覽

milmil 會自動記錄你觀看的每一集，包括時間戳和播放進度。歷史紀錄頁面提供可搜尋、可篩選的完整觀看記錄。

## 瀏覽紀錄

劇集以網格佈局顯示，包含：

- 帶有進度條疊加的劇集縮圖
- 動畫標題和集數
- 最後觀看時間
- 完成狀態

網格使用**無限捲動**分頁 — 向下捲動時會自動載入更早的紀錄。

## 篩選與搜尋

使用篩選列縮小歷史紀錄範圍：

| 篩選條件 | 說明 |
|--------|-------------|
| **全部** | 所有已觀看的劇集 |
| **在看** | 目前正在追的動畫 |
| **看完** | 已完結的動畫 |
| **棄追** | 已停止觀看的動畫 |

你也可以按動畫標題搜尋，快速找到特定作品。

<Callout type="info">
篩選和搜尋可以組合使用 — 結合狀態篩選和標題搜尋，精確找到你想要的內容。
</Callout>

## 批次操作

切換**批次模式**以一次選取多筆歷史紀錄。

<Steps>
<Step>
### 啟用批次模式

點擊工具列中的批次模式切換按鈕，進入多選模式。
</Step>
<Step>
### 選取紀錄

點擊個別項目來選取，或使用全選來選取所有可見項目。
</Step>
<Step>
### 執行操作

選擇操作 — **清除所選**會重設所選項目的觀看進度，**刪除**則會從歷史紀錄中完全移除。
</Step>
</Steps>

<Callout type="warn">
刪除歷史紀錄是永久性的，無法復原。
</Callout>
