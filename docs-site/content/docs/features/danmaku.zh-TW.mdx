## 概覽

彈幕在播放影片時橫向捲動顯示，重現 Bilibili 和 Niconico 等平台上的共同觀看體驗。milmil 整合了 [弹弹play开放弹幕网络（DandanPlay）](https://www.dandanplay.com/) 評論資料庫，每集可載入數千條時間同步的彈幕。

<Callout type="info">
彈幕功能需要連接 DandanPlay。請參閱[整合設定](/docs/configuration/integrations)進行設定。
</Callout>

## 彈幕來源

milmil 會將劇集與多個評論資料庫進行比對：

- **弹弹play开放弹幕网络（DandanPlay）** — 主要來源，擁有最大的中文彈幕庫
- **外部資料庫** — 由 DandanPlay 彙整的其他來源

使用播放器中的**來源分頁**瀏覽可用劇集並選擇要載入的評論集。當自動比對選錯劇集，或你想使用不同版本的彈幕時，此功能非常有用。

## 設定

從播放器設定面板中微調彈幕顯示：

| 設定 | 說明 |
| --- | --- |
| **不透明度** | 評論的透明度（0 &ndash; 100%） |
| **字型大小** | 相對於影片的文字大小 |
| **速度** | 評論橫向捲動的速度 |
| **顯示區域** | 彈幕覆蓋的影片範圍（上半部、全螢幕、底部） |
| **密度** | 同時顯示在螢幕上的最大彈幕數量 |

## 篩選與搜尋

**彈幕列表**面板按時間順序顯示所有已載入的彈幕。你可以：

- 按關鍵字搜尋彈幕
- 按彈幕類型篩選（滾動、頂部固定、底部固定）
- 跳轉到特定彈幕的時間點

## 切換顯示

使用播放器控制列中的彈幕按鈕可隨時顯示或隱藏彈幕。你的偏好設定會跨工作階段保留。
