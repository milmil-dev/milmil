## 概覽

milmil 的影片播放器基於 VideoJS 打造，採用自訂深色主題和模組化外掛系統。支援 HLS 串流、即時 MKV 轉 MP4 容器重新封裝，以及直接串流 URL。

## 外掛系統

播放器透過一系列內建外掛進行擴充，每個外掛負責特定功能。

### 播放外掛

- 播放速度控制（0.25x–4x）
- 自動跳轉到下一集
- A-B 循環，用於重播特定片段
- 跳過片頭/片尾

### 字幕外掛

- 多字幕軌道選擇（內嵌和外掛字幕）
- 樣式自訂 — 字型、大小、顏色、外框和位置
- 拖放 `.srt`、`.ass` 或 `.vtt` 檔案即時載入字幕

### 鍵盤外掛

- 完全可自訂的播放器操作快捷鍵
- 按 `?` 開啟鍵盤快捷鍵說明覆蓋層

### 媒體設定外掛

- 音訊增強器與等化器預設
- 影片濾鏡 — 亮度、對比度、飽和度和色調調整

### 手勢外掛

- 點擊播放/暫停，雙擊快轉
- 行動裝置上滑調整音量和亮度
- 長按快進

### 擷取外掛

- 將目前畫面擷取為 PNG 截圖
- 錄製可設定時長的 GIF 動畫片段

## 彈幕覆蓋層

即時彈幕在播放影片時橫向捲動顯示，資料來源為 DandanPlay。密度、不透明度、字型大小和顯示區域均可在播放器中設定。

<Callout type="info">
彈幕功能需要啟用 DandanPlay 整合。請參閱[整合設定](/docs/configuration/integrations)。
</Callout>

## 劇集側邊欄

可收合的側邊欄顯示目前動畫的所有劇集。在列表和網格檢視之間切換，無需離開播放器即可跳轉到任何一集。

## 相關推薦

播放器下方，milmil 會根據類型、標籤和系列關聯顯示相關動畫 — 方便你發現續集、外傳和類似作品。

## 技術資訊彈出視窗

點擊資訊圖示可檢視目前串流的技術詳情：影片解析度、編解碼器、位元率、容器格式和可用音軌。

## 觀看進度

播放位置每隔幾秒自動儲存。當你返回時，會從上次停止的位置繼續播放。連接 Bangumi 和 AniList 整合後，進度會同步到這些平台。
