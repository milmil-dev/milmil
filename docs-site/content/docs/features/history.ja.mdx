title: 視聴履歴
description: フィルタリング可能な履歴、一括操作、無限スクロールで視聴の進捗を追跡します。
---

## 概要

milmil は視聴したすべてのエピソードを自動的に記録し、タイムスタンプや再生の進捗を含めて保存します。履歴ページでは、視聴したすべてのコンテンツを検索・フィルタリングして確認できます。

## 履歴の閲覧

エピソードはグリッドレイアウトで表示され、以下の情報が含まれます：

- エピソードのサムネイルと進捗バーのオーバーレイ
- アニメタイトルとエピソード番号
- 最終視聴タイムスタンプ
- 視聴完了ステータス

グリッドは**無限スクロール**ページネーションを採用しており、スクロールダウンすると古いエントリが自動的に読み込まれます。

## フィルタリングと検索

フィルターバーを使って履歴を絞り込めます：

| フィルター | 説明 |
|--------|-------------|
| **すべて** | 視聴したすべてのエピソード |
| **視聴中** | 現在視聴中のアニメ |
| **完了** | 視聴が完了したアニメ |
| **中断** | 視聴を中断したアニメ |

アニメタイトルで検索して、特定のシリーズをすばやく見つけることもできます。

<Callout type="info">
フィルターと検索は組み合わせて使用できます。ステータスフィルターとタイトル検索を併用して、目的のエントリを正確に見つけましょう。
</Callout>

## 一括操作

**一括モード**を切り替えて、複数の履歴エントリを一度に選択できます。

<Steps>
<Step>
### 一括モードを有効にする

ツールバーの一括モードトグルをクリックして、複数選択モードに入ります。
</Step>
<Step>
### エントリを選択する

個々のエントリをクリックして選択するか、全選択を使って表示中のすべてのエントリを選択します。
</Step>
<Step>
### アクションを適用する

アクションを選択します — **選択をクリア**は選択したエントリの進捗をリセットし、**削除**は履歴から完全に削除します。
</Step>
</Steps>

<Callout type="warn">
履歴エントリの削除は永久的で、元に戻すことはできません。
</Callout>
