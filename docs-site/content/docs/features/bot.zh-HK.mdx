## 概覽

milmil 支援透過 Telegram、Discord 同通用 Webhook 進行互動機械人指令同推送通知。機械人係一等公民 — 佢哋可以搜尋動畫、管理下載、顯示時間表同控制訂閱。

## 機械人指令

Telegram 同 Discord 機械人支援相同嘅指令集：

| 指令 | 說明 |
|---|---|
| `/start` | 歡迎訊息同指令列表 |
| `/schedule` | 每週播出時間表，按星期分組 |
| `/search <查詢>` | 按標題搜尋動畫 |
| `/detail <id>` | 動畫詳情，包含封面圖片同評分 |
| `/downloads` | 進行中嘅下載同進度條 |
| `/subscribe <動畫>` | 設定新集數自動下載 |
| `/status` | 系統概覽（運行時間、磁碟、活躍串流） |
| `/mylist [狀態]` | 你嘅動畫收藏，按狀態篩選 |
| `/continue` | 最近觀看，附有繼續播放連結 |

## 互動功能

指令支援行內按鈕，方便快速操作：

- **搜尋結果** — 按鈕查看詳情、訂閱或下載
- **下載列表** — 暫停、繼續或取消按鈕
- **動畫詳情** — 訂閱、加入收藏或開始播放

<Callout type="info">
Discord 使用帶自動完成嘅斜線指令。Telegram 使用行內鍵盤同回調按鈕。
</Callout>

## 推送通知

設定邊啲事件觸發通知：

| 事件 | 說明 |
|---|---|
| 下載開始 | RSS 規則觸發咗新下載 |
| 下載完成 | 下載成功完成 |
| 下載失敗 | 下載遇到錯誤 |
| 媒體庫掃描完成 | 媒體庫掃描完成處理 |
| 系統錯誤 | 背景工作意外失敗 |

通知包括豐富嘅嵌入內容（Discord）或格式化訊息（Telegram），附有動畫封面圖片同中繼資料。

## 安全性

<Callout type="warn">
務必配置**允許嘅聊天 ID**（Telegram）或**允許嘅伺服器 ID**（Discord），限制邊啲人可以同你嘅機械人互動。如果冇呢啲限制，任何發現你機械人嘅人都可以控制你嘅 milmil 實例。
</Callout>
