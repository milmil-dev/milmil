## 概覽

milmil 提供即時通知，讓你不錯過任何重要事件。側邊欄中的鈴鐺圖示會顯示未讀數量徽章，方便快速檢視。

## 通知類型

| 類型 | 觸發條件 |
|------|---------|
| **掃描完成** | 媒體庫掃描完成處理新增或更新的檔案 |
| **比對完成** | 中繼資料比對解析了動畫或劇集 |
| **下載進度** | Torrent 或 HTTP 下載達到里程碑或完成 |
| **系統事件** | 錯誤、警告或維護提醒 |

## 傳送管道

通知透過多種管道傳送：

- **應用程式內** --- 透過 WebSocket 即時更新，可從側邊欄鈴鐺查看
- **推播通知** --- 桌面和行動裝置的瀏覽器推播
- **電子郵件提醒** --- 摘要式或按事件的電子郵件傳送

<Callout type="info">
推播通知需要在提示時授予瀏覽器通知權限。
</Callout>

## 通知歷史

**通知歷史**頁面列出所有過去的通知，包含時間戳和已讀/未讀狀態。用它來檢視你可能錯過的事件。

## 偏好設定

在**設定 > 通知**中配置哪些事件類型會觸發通知，以及透過哪些管道傳送。每種事件類型都可以獨立切換應用程式內、推播和電子郵件傳送。
