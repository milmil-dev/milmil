## 概览

milmil 提供文件管理工具来保持媒体库的整洁。使用可配置的模式批量重命名文件，并检测重复文件以回收存储空间。

## 文件重命名

使用模板模式重命名媒体文件，应用前可实时预览。

<Steps>
<Step>
### 选择文件

从媒体库详情页打开文件重命名工具，选择要重命名的文件。
</Step>
<Step>
### 配置模式

使用可用的标记选择重命名模式，例如 `[SubGroup] Title - E01.mkv`。
</Step>
<Step>
### 预览并应用

查看每个文件的重命名前后对比预览，然后应用重命名。
</Step>
</Steps>

<Callout type="info">
所有重命名操作都会记录在重命名历史中，你可以随时查看过往的更改。
</Callout>

## 重复检测

自动识别媒体库中的重复文件并批量清理。

### 检测方法

| 方法 | 说明 |
|--------|-------------|
| **文件哈希** | 通过内容哈希精确匹配（最准确） |
| **名称相似度** | 基于文件名的模糊匹配 |
| **剧集匹配** | 匹配到同一动画剧集的文件 |

### 清理流程

<Steps>
<Step>
### 扫描重复文件

对媒体库运行重复检测，找出匹配的文件组。
</Step>
<Step>
### 对比文件

使用文件路径对比视图决定保留哪个副本。
</Step>
<Step>
### 批量清理

跨多个分组选择重复文件，一次性删除或移动。
</Step>
</Steps>

<Callout type="warn">
删除的文件会被永久移除。在确认批量删除前，请仔细检查对比视图。
</Callout>
