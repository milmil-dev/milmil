## 再生モード

milmil は 3 つのストリーミングモードに対応し、最適なオプションを自動選択します：

### ダイレクトプレイ

バイトレンジリクエストでオリジナルファイルを直接配信。トランスコードのオーバーヘッドなし — 最高の画質とパフォーマンス。

### コンテナリマックス

MKV コンテナを MP4 にオンザフライでリマックスし、映像や音声の再エンコードは不要。MKV をネイティブサポートしないブラウザでの再生を可能にします。

### HLS トランスコード

ソースフォーマットがブラウザと互換性がない場合、FFmpeg で HLS（HTTP ライブストリーミング）にフルトランスコード。以下を含みます：

- アダプティブビットレートストリーミング
- セッションベースのキャッシュで高速シーク
- 設定可能な画質プリセット

## 弾幕（弾幕コメント）

DandanPlay から取得したリアルタイム弾幕コメントが映像にオーバーレイ表示されます。再生中にコメントが画面をスクロールし、共有視聴体験を作り出します。

プレーヤー設定で弾幕の密度、透明度、フォントサイズを設定できます。

## 字幕

milmil は以下に対応：

- **埋め込み字幕** — MKV/MP4 コンテナから抽出（ASS、SRT など）
- **外部字幕** — 動画と同じ場所にある `.srt`、`.ass`、`.vtt` ファイル
- 言語選択付きの複数字幕トラック

## 視聴進捗

視聴進捗は自動的に保存・同期されます：

- どのデバイスからでも前回の続きから再開
- ホームページに視聴を再開セクションを表示
- Bangumi および AniList との進捗同期（接続時）
