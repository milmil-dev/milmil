## 개요

탄막(탄막 코멘트)은 재생 중 비디오 위를 스크롤하며 지나가는 코멘트로, Bilibili나 Niconico 같은 플랫폼에서 경험할 수 있는 공동 시청 경험을 재현합니다. milmil은 [DandanPlay](https://www.dandanplay.com/) 코멘트 데이터베이스와 연동하여 에피소드당 수천 개의 시간 동기화된 코멘트를 가져옵니다.

<Callout type="info">
탄막 기능을 사용하려면 DandanPlay 연결이 필요합니다. 설정 방법은 [연동 설정](/docs/configuration/integrations)을 참조하세요.
</Callout>

## 탄막 소스

milmil은 여러 코멘트 데이터베이스에서 에피소드를 매칭합니다:

- **DandanPlay** — 가장 큰 중국어 코멘트 풀을 보유한 기본 소스
- **외부 데이터베이스** — DandanPlay가 집계한 추가 소스

플레이어의 **소스 탭**을 사용하여 사용 가능한 에피소드를 탐색하고 로드할 코멘트 세트를 선택할 수 있습니다. 자동 매칭이 잘못된 에피소드를 선택했거나 다른 릴리스의 코멘트를 원할 때 유용합니다.

## 설정

플레이어 설정 패널에서 탄막 표시를 세밀하게 조정할 수 있습니다:

| 설정 | 설명 |
| --- | --- |
| **불투명도** | 코멘트의 투명도 (0 &ndash; 100%) |
| **글꼴 크기** | 비디오 대비 텍스트 크기 |
| **속도** | 코멘트가 화면을 가로질러 스크롤하는 속도 |
| **표시 영역** | 비디오에서 코멘트가 표시되는 영역 (상단 절반, 전체, 하단) |
| **밀도** | 동시에 화면에 표시되는 최대 코멘트 수 |

## 필터링 및 검색

**탄막 목록** 패널은 로드된 모든 코멘트를 시간순으로 표시합니다. 다음 기능을 사용할 수 있습니다:

- 키워드로 코멘트 검색
- 코멘트 유형별 필터 (스크롤, 상단 고정, 하단 고정)
- 특정 코멘트의 타임스탬프로 이동

## 토글

플레이어 컨트롤의 탄막 버튼을 사용하여 언제든지 코멘트를 표시하거나 숨길 수 있습니다. 설정은 세션 간에 유지됩니다.
