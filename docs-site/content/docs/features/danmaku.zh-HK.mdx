## 概覽

彈幕（彈幕評論）喺播放期間滾動穿過影片畫面，重現類似 Bilibili 同 Niconico 等平台嘅共同觀看體驗。milmil 整合咗 [弹弹play开放弹幕网络（DandanPlay）](https://www.dandanplay.com/) 評論資料庫，為每集拉取數以千計嘅時間同步評論。

<Callout type="info">
彈幕需要 DandanPlay 連接。請參閱[整合設定](/docs/configuration/integrations)進行設定。
</Callout>

## 彈幕來源

milmil 會將劇集比對到多個評論資料庫：

- **弹弹play开放弹幕网络（DandanPlay）** — 主要來源，擁有最大嘅中文評論庫
- **外部資料庫** — 由 DandanPlay 聚合嘅其他來源

喺播放器入面用**來源分頁**瀏覽可用嘅劇集，並揀選要載入邊個評論集。當自動比對揀錯咗劇集，或者你想要其他版本嘅評論時，呢個功能特別有用。

## 設定

喺播放器設定面板微調彈幕顯示：

| 設定 | 說明 |
| --- | --- |
| **透明度** | 評論嘅透明度（0 &ndash; 100%） |
| **字體大小** | 相對於影片嘅文字大小 |
| **速度** | 評論滾動穿過畫面嘅速度 |
| **顯示區域** | 影片覆蓋範圍（上半部、全部、底部） |
| **密度** | 同時顯示喺畫面上嘅最大評論數量 |

## 篩選同搜尋

**彈幕列表**面板按時間順序顯示所有已載入嘅評論。你可以：

- 透過關鍵字搜尋評論
- 按評論類型篩選（滾動、置頂、置底）
- 跳轉到特定評論嘅時間戳

## 切換

用播放器控制列入面嘅彈幕按鈕隨時顯示或隱藏評論。你嘅偏好設定會跨工作階段記住。
