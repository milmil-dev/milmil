## Overview

milmil delivers real-time notifications so you never miss important events. A bell icon in the sidebar displays an unread count badge for quick access.

## Notification Types

| Type | Trigger |
|------|---------|
| **Scan completion** | Library scan finishes processing new or updated files |
| **Match completion** | Metadata matching resolves an anime or episode |
| **Download progress** | Torrent or HTTP download reaches milestones or completes |
| **System events** | Errors, warnings, or maintenance alerts |

## Delivery Channels

Notifications are delivered through multiple channels:

- **In-app** --- real-time updates via WebSocket, visible from the sidebar bell
- **Push notifications** --- browser push for desktop and mobile
- **Email alerts** --- digest or per-event email delivery

<Callout type="info">
Push notifications require granting browser notification permissions when prompted.
</Callout>

## Notification History

The **Notification History** page lists all past notifications with timestamps and read/unread status. Use it to review events you may have missed.

## Preferences

Configure which event types trigger notifications and through which channels under **Settings > Notifications**. Each event type can be independently toggled for in-app, push, and email delivery.
