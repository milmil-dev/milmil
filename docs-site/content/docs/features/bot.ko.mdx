## 개요

milmil은 Telegram, Discord, 일반 웹훅을 통한 인터랙티브 봇 명령어와 푸시 알림을 지원합니다. 봇은 핵심 기능으로서 애니메이션 검색, 다운로드 관리, 일정 확인, 구독 제어가 가능합니다.

## 봇 명령어

Telegram과 Discord 봇 모두 동일한 명령어 세트를 지원합니다:

| 명령어 | 설명 |
|---|---|
| `/start` | 환영 메시지 및 명령어 목록 |
| `/schedule` | 요일별 그룹화된 주간 방영 일정 |
| `/search <query>` | 제목으로 애니메이션 검색 |
| `/detail <id>` | 커버 이미지 및 평점이 포함된 애니메이션 상세 정보 |
| `/downloads` | 진행률 바가 표시된 활성 다운로드 |
| `/subscribe <anime>` | 새 에피소드 자동 다운로드 설정 |
| `/status` | 시스템 개요 (가동 시간, 디스크, 활성 스트림) |
| `/mylist [status]` | 상태별로 필터링된 애니메이션 컬렉션 |
| `/continue` | 이어보기 링크가 포함된 최근 시청 목록 |

## 인터랙티브 기능

명령어는 빠른 작업을 위한 인라인 버튼을 지원합니다:

- **검색 결과** — 상세 보기, 구독, 다운로드 버튼
- **다운로드 목록** — 일시정지, 재개, 취소 버튼
- **애니메이션 상세** — 구독, 컬렉션 추가, 재생 시작 버튼

<Callout type="info">
Discord는 자동 완성이 지원되는 슬래시 명령어를 사용합니다. Telegram은 인라인 키보드와 콜백 버튼을 사용합니다.
</Callout>

## 푸시 알림

알림을 트리거하는 이벤트를 구성합니다:

| 이벤트 | 설명 |
|---|---|
| 다운로드 시작 | RSS 규칙이 새 다운로드를 트리거 |
| 다운로드 완료 | 다운로드가 성공적으로 완료 |
| 다운로드 실패 | 다운로드 중 오류 발생 |
| 라이브러리 스캔 완료 | 라이브러리 스캔 처리 완료 |
| 시스템 오류 | 백그라운드 작업이 예기치 않게 실패 |

알림에는 애니메이션 커버 이미지와 메타데이터가 포함된 리치 임베드(Discord) 또는 포맷된 메시지(Telegram)가 포함됩니다.

## 보안

<Callout type="warn">
반드시 **허용된 채팅 ID** (Telegram) 또는 **허용된 길드 ID** (Discord)를 설정하여 봇과 상호작용할 수 있는 사용자를 제한하세요. 이 제한이 없으면 봇을 발견한 누구나 milmil 인스턴스를 제어할 수 있습니다.
</Callout>
