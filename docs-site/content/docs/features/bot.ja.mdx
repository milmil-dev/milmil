## 概要

milmil は Telegram、Discord、汎用 Webhook を通じたインタラクティブなボットコマンドとプッシュ通知をサポートしています。ボットはファーストクラスの機能であり、アニメの検索、ダウンロード管理、スケジュール表示、サブスクリプション管理が可能です。

## ボットコマンド

Telegram と Discord の両方のボットが同じコマンドセットをサポートしています：

| コマンド | 説明 |
|---|---|
| `/start` | ウェルカムメッセージとコマンド一覧 |
| `/schedule` | 曜日別グループ分けの週間放送スケジュール |
| `/search <query>` | タイトルでアニメを検索 |
| `/detail <id>` | カバー画像とスコア付きのアニメ詳細 |
| `/downloads` | プログレスバー付きのアクティブダウンロード |
| `/subscribe <anime>` | 新エピソードの自動ダウンロードを設定 |
| `/status` | システム概要（稼働時間、ディスク、アクティブストリーム） |
| `/mylist [status]` | ステータスでフィルタリングしたアニメコレクション |
| `/continue` | 再開リンク付きの最近の視聴履歴 |

## インタラクティブ機能

コマンドはクイックアクション用のインラインボタンをサポートしています：

- **検索結果** — 詳細表示、サブスクリプション、ダウンロードのボタン
- **ダウンロードリスト** — 一時停止、再開、キャンセルのボタン
- **アニメ詳細** — サブスクリプション、コレクションに追加、再生開始

<Callout type="info">
Discord はオートコンプリート付きのスラッシュコマンドを使用します。Telegram はインラインキーボードとコールバックボタンを使用します。
</Callout>

## プッシュ通知

どのイベントが通知をトリガーするかを設定します：

| イベント | 説明 |
|---|---|
| ダウンロード開始 | RSS ルールが新しいダウンロードをトリガー |
| ダウンロード完了 | ダウンロードが正常に完了 |
| ダウンロード失敗 | ダウンロードでエラーが発生 |
| ライブラリスキャン完了 | ライブラリスキャンの処理が完了 |
| システムエラー | バックグラウンドジョブが予期せず失敗 |

通知には、アニメのカバー画像とメタデータを含むリッチ埋め込み（Discord）またはフォーマットされたメッセージ（Telegram）が含まれます。

## セキュリティ

<Callout type="warn">
必ず**許可されたチャット ID**（Telegram）または**許可されたギルド ID**（Discord）を設定して、ボットと対話できるユーザーを制限してください。これらの制限がないと、ボットを発見した誰もが milmil インスタンスを操作できてしまいます。
</Callout>
