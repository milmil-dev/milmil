## 시청 상태

상태별로 애니메이션을 정리합니다:

| 상태 | 설명 |
|--------|-------------|
| **시청 중** | 현재 시청 중 |
| **계획** | 시청 예정 |
| **완료** | 시청 완료 |
| **일시정지** | 보류 중 |
| **중단** | 시청 중단 |

## 평점

개인 기준으로 애니메이션을 평가합니다. 평점은 연결된 서비스 (Bangumi, AniList)와 양방향 동기화됩니다.

## 이어서 보기

홈페이지에 최근 시청 기록이 표시됩니다:

- 에피소드 진행 바
- 남은 시간
- 원클릭 재생 재개

## 외부 동기화

Bangumi 또는 AniList에 연결하면 컬렉션이 자동으로 동기화됩니다:

- 시청 상태 변경이 연결된 서비스에 반영
- 평점 양방향 동기화
- 진행 상황 실시간 업데이트

**설정 > 연동**에서 동기화를 구성합니다.
