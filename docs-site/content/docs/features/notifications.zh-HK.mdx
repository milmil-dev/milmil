## 概覽

milmil 提供即時通知，令你唔會錯過重要事件。側邊欄嘅鈴鐺圖示會顯示未讀數量徽章，方便快速查閱。

## 通知類型

| 類型 | 觸發條件 |
|------|---------|
| **掃描完成** | 媒體庫掃描完成處理新增或更新嘅檔案 |
| **比對完成** | 中繼資料比對解析到動畫或劇集 |
| **下載進度** | 種子或 HTTP 下載達到里程碑或完成 |
| **系統事件** | 錯誤、警告或維護提醒 |

## 傳送渠道

通知透過多個渠道傳送：

- **應用程式內** --- 透過 WebSocket 即時更新，可從側邊欄鈴鐺查閱
- **推送通知** --- 桌面同流動裝置嘅瀏覽器推送
- **電郵提醒** --- 摘要或逐事件電郵傳送

<Callout type="info">
推送通知需要喺收到提示時授予瀏覽器通知權限。
</Callout>

## 通知歷史

**通知歷史**頁面列出所有過往通知，附有時間戳同已讀/未讀狀態。用嚟查閱你可能錯過嘅事件。

## 偏好設定

喺**設定 > 通知**下配置邊啲事件類型觸發通知，以及透過邊啲渠道傳送。每個事件類型都可以獨立切換應用程式內、推送同電郵傳送。
