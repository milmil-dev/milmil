## 概覽

設定頁面以分頁面板組織，每個面板涵蓋不同的配置領域。可從側邊欄或導覽選單開啟。

## 面板

### 一般

設定偏好的**顯示語言**（EN、JA、ZH-CN、ZH-TW、ZH-HK、KO），選擇日曆檢視的**每週起始日**，以及切換**自動加入收藏**，讓新比對到的動畫自動加入你的收藏。

### 播放器

自訂字幕外觀 — **字型大小**、**字型**和**樣式預設** — 並檢視播放控制的預設**鍵盤快捷鍵**（播放/暫停、快轉、音量、全螢幕等）。

### 帳號

管理你的**使用者名稱**，產生或撤銷用於第三方存取的 **API 權杖**，以及檢視或終止進行中的**工作階段**。

### 整合

連接外部服務：

| 服務 | 詳情 |
|---------|---------|
| **DandanPlay** | 檔案雜湊比對和彈幕 |
| **Trakt.tv** | 透過 OAuth 裝置碼流程同步觀看紀錄 |

<Callout type="info">
Trakt.tv 使用裝置碼流程 — milmil 會顯示一組代碼，你在任何瀏覽器上前往 trakt.tv/activate 輸入即可。
</Callout>

### 下載

檢視目前的**下載引擎狀態**，並執行**健康檢查**以驗證 Torrent 客戶端和 RSS 訂閱是否正常運作。

### 通知

按事件類型配置**推播**和**電子郵件**通知偏好（例如新劇集上架、下載完成、掃描完成）。

### 備份

排程自動備份至 **WebDAV** 或 **S3 相容**儲存空間。設定備份頻率和保留策略以保護你的資料庫和配置。

<Callout type="warn">
備份包含你的資料庫和設定，但不包含媒體檔案。請確保你的媒體儲存空間有自己的冗餘備份。
</Callout>

### 儲存空間

檢視所有已配置後端的**快取統計**和**儲存空間使用量**。使用**清除快取**操作來回收縮圖和暫存檔佔用的磁碟空間。

### 關於

顯示目前的**應用程式版本**、開源**授權條款**和專案**致謝**。
