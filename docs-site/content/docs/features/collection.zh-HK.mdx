---
title: 收藏
description: 追蹤你嘅動畫睇劇進度、評分，同埋同外部服務同步。
---

## 觀看狀態

按狀態整理你嘅動畫：

| 狀態 | 說明 |
|--------|-------------|
| **在看** | 正喺度睇 |
| **計劃看** | 計劃睇 |
| **看過** | 已經睇完咗 |
| **擱置** | 暫時擱置 |
| **拋棄** | 停止睇 |

## 評分

按個人評分標準幫動畫評分。評分會同已連接嘅服務（Bangumi、AniList）雙向同步。

## 繼續觀看

首頁會顯示你最近嘅睇劇記錄：

- 劇集進度條
- 剩餘時間
- 一鍵繼續播放

## 外部同步

連接咗 Bangumi 或者 AniList 之後，你嘅收藏會自動同步：

- 觀看狀態變更同步到已連接嘅服務
- 評分雙向同步
- 進度即時更新

喺 **設定 > 整合** 入面設定同步。
