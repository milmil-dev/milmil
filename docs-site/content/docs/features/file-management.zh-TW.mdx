## 概覽

milmil 提供檔案管理工具，讓你的媒體庫保持整齊。使用可配置的模式批次重新命名檔案，並偵測重複檔案以回收儲存空間。

## 檔案重新命名

使用模式範本重新命名媒體檔案，套用前可即時預覽。

<Steps>
<Step>
### 選擇檔案

從媒體庫詳情頁開啟檔案重新命名工具，選擇要重新命名的檔案。
</Step>
<Step>
### 設定模式

使用可用的標記選擇重新命名模式，例如 `[SubGroup] Title - E01.mkv`。
</Step>
<Step>
### 預覽並套用

檢視每個檔案的前後對比預覽，然後套用重新命名。
</Step>
</Steps>

<Callout type="info">
所有重新命名操作都會記錄在重新命名歷史中，你可以隨時檢視過去的變更。
</Callout>

## 重複偵測

自動識別媒體庫中的重複檔案，並批次清理。

### 偵測方法

| 方法 | 說明 |
|--------|-------------|
| **檔案雜湊** | 透過內容雜湊精確比對（最準確） |
| **名稱相似度** | 以檔案名稱進行模糊比對 |
| **劇集比對** | 比對到相同動畫劇集的檔案 |

### 清理流程

<Steps>
<Step>
### 掃描重複檔案

對媒體庫執行重複偵測，找出匹配的檔案群組。
</Step>
<Step>
### 比較檔案

使用檔案路徑比較檢視來決定要保留哪個副本。
</Step>
<Step>
### 批次清理

跨多個群組選取重複檔案，一次性刪除或移動。
</Step>
</Steps>

<Callout type="warn">
刪除的檔案會被永久移除。確認批次刪除前，請仔細檢查比較檢視。
</Callout>
