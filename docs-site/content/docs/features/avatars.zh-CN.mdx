## 概览

账号可以带一张图片，而不只是一个首字母。设定一次，凡是出现账号的地方都会用它：Web 侧边栏与账号面板、macOS 客户端，以及连上这台服务器的 Jellyfin 客户端。

## 怎么设

打开**设置 › 账号**：

- **上传图片** —— PNG、JPEG 或 WebP，最大 2 MB。拖到卡片上或选择文件。
- **用角色立绘** —— 从收藏里挑一部作品，再选它的一个角色。立绘由服务器端从提供元数据的来源复制过来，不会做外链盗图。

图片会居中裁成正方形，以 JPEG 存成 512 px 与 128 px 两份，放在服务器的资料目录下。删除后会恢复成首字母。

## 会在哪里出现

| 客户端 | 位置 |
|--------|------|
| **Web** | 侧边栏、账号菜单、账号设置 |
| **macOS** | 账号设置，以及任何显示已登录账号的地方 |
| **Jellyfin 客户端** | 用户主图片——Infuse、Apple TV 客户端，以及任何会显示用户头像的应用 |

头像 URL 带版本参数，所以换图之后所有客户端的缓存会一次性失效。

<Callout type="info">
头像是刻意不做鉴权的：`<img>` 标签和外部播放器都没法送 bearer token，用户 id 是 UUID，而一张头像也算不上秘密。
</Callout>

## API

<Callout type="info">
`PUT /api/v1/auth/me/avatar` 接受 multipart 文件或带 `source_url` 的 JSON body；同一路径的 `DELETE` 会删除头像。`GET /api/v1/users/{id}/avatar` 提供图片。`/auth/me` 与登录响应都会带 `avatar_url`。见 [API 参考](/docs/api)。
</Callout>

<Callout type="warn">
`source_url` 由服务器去取，因此只允许公网地址——解析到回环、私有网段或链路本地地址的 URL 会被拒绝，重定向到这些地址同样会被拒绝。
</Callout>
