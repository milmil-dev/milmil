## 季度日曆

睇每週每天播出嘅動畫，資料來自 Bangumi 嘅時間表。日曆顯示：

- 醒目標示今日更新
- 集數同播出時間
- 快速存取動畫詳情頁

## 熱門

睇當前熱門動畫，按 Bangumi 社群活躍度同評分排名。

## 搜尋

全文搜尋動畫資料庫，支援篩選：

- **類型** — 動作、喜劇、劇情、奇幻、戀愛等
- **標籤** — 特定主題同內容標籤
- **年份/季度** — 按播出日期篩選
- **格式** — TV、劇場版、OVA、ONA、特別篇
- **評分** — 最低評分門檻
- **成人內容** — 切換 NSFW 結果

## 動畫詳情

每個動畫詳情頁包含：

- 封面同橫幅圖片
- 簡介同中繼資料
- 劇集列表及播放狀態
- 角色同聲優資訊
- 相關作品同續作
- 推薦
- 社群評價同評論
- 可用種子
