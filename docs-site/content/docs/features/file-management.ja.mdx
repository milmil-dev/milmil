## 概要

milmil はライブラリを整理するためのファイル管理ツールを提供します。設定可能なパターンを使ってファイルを一括リネームし、重複ファイルを検出してストレージ容量を回収できます。

## ファイルリネーム

パターンテンプレートを使用してメディアファイルをリネームします。変更を適用する前にライブプレビューで確認できます。

<Steps>
<Step>
### ファイルを選択

ライブラリ詳細ページからファイルリネームツールを開き、リネームするファイルを選択します。
</Step>
<Step>
### パターンを設定

利用可能なトークンを使ってリネームパターンを選択します（例：`[SubGroup] Title - E01.mkv`）。
</Step>
<Step>
### プレビューして適用

各ファイルの変更前/変更後のプレビューを確認してから、リネームを適用します。
</Step>
</Steps>

<Callout type="info">
すべてのリネーム操作はリネーム履歴に記録されるため、過去の変更をいつでも確認できます。
</Callout>

## 重複検出

ライブラリ内の重複ファイルを自動的に特定し、一括でクリーンアップします。

### 検出方法

| 方法 | 説明 |
|--------|-------------|
| **ファイルハッシュ** | コンテンツハッシュによる完全一致（最も正確） |
| **名前の類似性** | ファイル名のあいまいマッチング |
| **エピソードマッチ** | 同じアニメエピソードにマッチしたファイル |

### クリーンアップワークフロー

<Steps>
<Step>
### 重複をスキャン

ライブラリに対して重複検出を実行し、一致するファイルグループを表示します。
</Step>
<Step>
### ファイルを比較

ファイルパス比較ビューを使用して、どのコピーを残すか判断します。
</Step>
<Step>
### 一括クリーンアップ

複数のグループにまたがる重複を選択し、1 回の操作で削除または移動します。
</Step>
</Steps>

<Callout type="warn">
削除されたファイルは永久に削除されます。一括削除を確認する前に、比較ビューをよく確認してください。
</Callout>
