## 概要

milmil はリアルタイム通知を配信し、重要なイベントを見逃さないようにします。サイドバーのベルアイコンに未読数バッジが表示され、すばやくアクセスできます。

## 通知タイプ

| タイプ | トリガー |
|------|---------|
| **スキャン完了** | ライブラリスキャンが新規または更新されたファイルの処理を完了 |
| **マッチ完了** | メタデータマッチングがアニメまたはエピソードを解決 |
| **ダウンロード進捗** | トレントまたは HTTP ダウンロードがマイルストーンに到達または完了 |
| **システムイベント** | エラー、警告、またはメンテナンスアラート |

## 配信チャンネル

通知は複数のチャンネルを通じて配信されます：

- **アプリ内** --- WebSocket によるリアルタイム更新、サイドバーのベルから確認可能
- **プッシュ通知** --- デスクトップおよびモバイル向けブラウザプッシュ
- **メールアラート** --- ダイジェストまたはイベントごとのメール配信

<Callout type="info">
プッシュ通知を利用するには、プロンプトが表示された際にブラウザの通知許可を付与する必要があります。
</Callout>

## 通知履歴

**通知履歴**ページには、タイムスタンプと既読/未読ステータス付きで過去のすべての通知が一覧表示されます。見逃したイベントの確認に使用できます。

## 設定

どのイベントタイプが通知をトリガーするか、またどのチャンネルを通じて通知するかを**設定 > 通知**で設定できます。各イベントタイプは、アプリ内、プッシュ、メールの配信を個別に切り替えられます。
