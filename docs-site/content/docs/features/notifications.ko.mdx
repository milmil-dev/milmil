## 개요

milmil은 중요한 이벤트를 놓치지 않도록 실시간 알림을 제공합니다. 사이드바의 종 아이콘에 읽지 않은 알림 수 배지가 표시되어 빠르게 확인할 수 있습니다.

## 알림 유형

| 유형 | 트리거 |
|------|---------|
| **스캔 완료** | 라이브러리 스캔이 새 파일 또는 업데이트된 파일 처리를 완료 |
| **매칭 완료** | 메타데이터 매칭이 애니메이션 또는 에피소드를 확인 |
| **다운로드 진행** | 토렌트 또는 HTTP 다운로드가 마일스톤에 도달하거나 완료 |
| **시스템 이벤트** | 오류, 경고, 유지보수 알림 |

## 전달 채널

알림은 여러 채널을 통해 전달됩니다:

- **인앱** --- WebSocket을 통한 실시간 업데이트, 사이드바 종 아이콘에서 확인 가능
- **푸시 알림** --- 데스크톱 및 모바일용 브라우저 푸시
- **이메일 알림** --- 요약 또는 이벤트별 이메일 전달

<Callout type="info">
푸시 알림을 사용하려면 브라우저에서 알림 권한을 허용해야 합니다.
</Callout>

## 알림 기록

**알림 기록** 페이지에는 타임스탬프와 읽음/읽지 않음 상태가 포함된 모든 과거 알림이 나열됩니다. 놓쳤을 수 있는 이벤트를 확인하는 데 사용할 수 있습니다.

## 환경설정

**설정 > 알림**에서 어떤 이벤트 유형이 알림을 트리거하고 어떤 채널을 통해 전달할지 구성합니다. 각 이벤트 유형은 인앱, 푸시, 이메일 전달을 개별적으로 설정할 수 있습니다.
