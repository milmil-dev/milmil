## 概要

弾幕（コメント）は再生中にビデオ上をスクロールし、Bilibili やニコニコ動画のようなみんなで視聴する体験を再現します。milmil は [DandanPlay](https://www.dandanplay.com/) コメントデータベースと連携し、エピソードごとに数千件の時間同期コメントを取得します。

<Callout type="info">
弾幕には DandanPlay の接続が必要です。設定方法は[インテグレーション](/docs/configuration/integrations)をご覧ください。
</Callout>

## 弾幕ソース

milmil はエピソードを複数のコメントデータベースに対してマッチングします：

- **DandanPlay** — 最大の中国語コメントプールを持つ主要ソース
- **外部データベース** — DandanPlay が集約した追加ソース

プレーヤーの**ソースタブ**を使って、利用可能なエピソードを閲覧し、読み込むコメントセットを選択できます。自動マッチングが間違ったエピソードを選んだ場合や、別のリリースのコメントが必要な場合に便利です。

## 設定

プレーヤー設定パネルから弾幕の表示を細かく調整できます：

| 設定 | 説明 |
| --- | --- |
| **不透明度** | コメントの透過度（0 &ndash; 100%） |
| **フォントサイズ** | ビデオに対するテキストサイズ |
| **速度** | コメントが画面をスクロールする速さ |
| **表示エリア** | ビデオの表示領域（上半分、全画面、下部） |
| **密度** | 同時に画面上に表示されるコメントの最大数 |

## フィルタリングと検索

**弾幕リスト**パネルには、読み込まれたすべてのコメントが時系列順に表示されます。以下の操作が可能です：

- キーワードでコメントを検索
- コメントタイプでフィルタリング（スクロール、上部固定、下部固定）
- 特定のコメントのタイムスタンプにジャンプ

## 切り替え

プレーヤーコントロールの弾幕ボタンを使って、いつでもコメントの表示・非表示を切り替えられます。設定はセッション間で保持されます。
