## 概覽

macOS 客戶端可以將一部番複製落本機，連唔到伺服器嗰陣一樣播得。佢唔係第二個媒體庫，而係「就快要睇嘅嘢」嘅快取：受你設定嘅磁碟配額管住，睇完之後自己會消失。

<Callout type="info">
離線下載係 macOS 客戶端嘅功能。伺服器只係提供一個講明「一份副本要乜」嘅端點；Web 端淨係做串流，唔會留本機副本。
</Callout>

## 一份副本入面有乜

每一集都完整留低，播嘅時候唔使再攞任何嘢：

| 部分 | 說明 |
|------|------|
| **媒體檔案** | 原始檔案，逐個 byte 複製。唔轉碼、唔重新封裝。 |
| **外掛字幕** | 伺服器知道嘅每一條 sidecar 字幕軌，連語言同標題。內嵌字幕跟住檔案本身一齊留低。 |
| **彈幕** | 做副本嗰陣嘅彈幕快照。 |

## 自己揀嚟留

喺作品頁或者**離線**分頁揀要留嘅劇集。進度逐集顯示，重開之後會續傳；可以將某一集釘住，下面啲規則就唔會刪佢。

## 自動留

自動保留**預設係熄咗**——唔問一聲就食咗你幾個 GB 係好討厭嘅事。喺**設定 › 離線**開咗之後，佢會：

- 為你追緊嘅每部番留住之後 **1、2、3 或者 5** 集未睇嘅劇集。
- 開機嗰陣、每個鐘、同埋伺服器話有新集可以睇嗰陣各跑一次。
- 喺你**最後一次播完之後 24 個鐘**刪走睇完嘅副本（釘咗嘅除外）。
- 靠優先刪走最早睇完嘅副本，將佔用控喺配額之內——**5、10、20、50 或者 100 GB**。釘咗嘅副本永遠唔會被刪。

## 播放

本機副本喺播放階梯嘅最上層：

1. **離線副本** —— 直接由 Mac 自己嘅磁碟播。
2. **本機檔案** —— 經掛載嘅磁碟區讀媒體庫檔案。
3. **直接串流** —— 向伺服器發 byte-range 請求。
4. **重新封裝** —— MKV 轉做 MP4。
5. **HLS 轉碼** —— 自適應串流。

有一層用唔到嘅時候播放器會退落下一層，所以副本喺 App 唔知情之下俾人刪咗，都只係變返串流啫。

## 保持最新

清單入面每個檔案都帶 ETag 同大小。伺服器上嘅檔案一有變——換咗個好啲嘅版本、整返好一次爛咗嘅下載——本機副本就對唔上，下一輪規則跑嗰陣會重新載。

## API

<Callout type="info">
`GET /api/v1/anime/{bangumiId}/offline-manifest` 一次過回一部番全部可播嘅劇集：檔案 URL、大小、ETag、容器同編碼、字幕軌、彈幕 URL——客戶端做一份副本要嘅嘢全部喺度。睇 [API 參考](/docs/api)。
</Callout>
