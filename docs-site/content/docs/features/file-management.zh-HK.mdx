## 概覽

milmil 提供檔案管理工具，幫你保持媒體庫嘅整潔。用可配置嘅模式批次重新命名檔案，並偵測重複檔案嚟釋放儲存空間。

## 檔案重新命名

用模式範本重新命名媒體檔案，套用前提供即時預覽。

<Steps>
<Step>
### 揀選檔案

從媒體庫詳情頁打開檔案重新命名工具，揀選要重新命名嘅檔案。
</Step>
<Step>
### 設定模式

用可用嘅代號揀選重新命名模式，例如 `[SubGroup] Title - E01.mkv`。
</Step>
<Step>
### 預覽同套用

檢視每個檔案嘅前後對比預覽，然後套用重新命名。
</Step>
</Steps>

<Callout type="info">
所有重新命名操作都會記錄喺重新命名歷史中，你可以隨時查閱過往嘅更改。
</Callout>

## 重複偵測

自動識別媒體庫中嘅重複檔案，並批次清理。

### 偵測方法

| 方法 | 說明 |
|--------|-------------|
| **檔案雜湊** | 透過內容雜湊精確比對（最準確） |
| **名稱相似度** | 對檔案名稱進行模糊比對 |
| **劇集比對** | 比對到同一動畫劇集嘅檔案 |

### 清理流程

<Steps>
<Step>
### 掃描重複檔案

對媒體庫執行重複偵測，搵出比對到嘅檔案群組。
</Step>
<Step>
### 比較檔案

用檔案路徑比較檢視嚟決定保留邊個副本。
</Step>
<Step>
### 批次清理

跨多個群組揀選重複檔案，一次過刪除或移動。
</Step>
</Steps>

<Callout type="warn">
刪除嘅檔案會被永久移除。確認批次刪除前，請仔細檢查比較檢視。
</Callout>
