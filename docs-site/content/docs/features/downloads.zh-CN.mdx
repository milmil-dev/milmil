## 种子客户端

milmil 内置种子客户端，支持：

- 可配置的做种比率和时间限制
- DHT 和对等交换支持
- 下载进度跟踪
- 暂停/恢复控制

### 配置

| 设置 | 默认值 | 说明 |
|---------|---------|-------------|
| `TORRENT_LISTEN_PORT` | `42069` | DHT/对等端口 |
| `SEED_RATIO` | `1.0` | 目标做种比率 |
| `SEED_TIME_MINUTES` | `60` | 最短做种时间 |

## 种子搜索

在单一界面中跨多个种子提供商搜索：

- **Nyaa** — 最大的动画种子追踪器
- **DMHY** — 中文动画种子
- **Mikan** — 蜜柑计划聚合器
- **Bangumi.moe** — Bangumi 种子追踪器
- **ACG.rip** — ACG 资源追踪器

按分辨率、字幕组和文件类型筛选结果。

## RSS 自动下载

订阅 RSS 源，自动下载剧集：

1. 添加 RSS 源 URL
2. 配置过滤器（正则表达式、分辨率、字幕组偏好）
3. milmil 定期检查源并下载匹配的剧集
4. 下载的文件自动扫描并匹配

### 下载后处理流程

下载完成后，milmil 自动执行：

1. 扫描下载的文件
2. 匹配到正确的动画和剧集
3. 从提供商补充元数据
4. 发送通知

## HTTP 下载

milmil 还支持直接 HTTP 下载，具备断点续传功能。
