## 概覽

milmil 透過 Telegram、Discord 和通用 Webhook 支援互動式機器人指令和推播通知。機器人是一等功能 — 可以搜尋動畫、管理下載、顯示時間表和控制訂閱。

## 機器人指令

Telegram 和 Discord 機器人支援相同的指令集：

| 指令 | 說明 |
|---|---|
| `/start` | 歡迎訊息和指令列表 |
| `/schedule` | 按星期分組的每週播出時間表 |
| `/search <query>` | 按標題搜尋動畫 |
| `/detail <id>` | 動畫詳情，含封面圖和評分 |
| `/downloads` | 進行中的下載及進度條 |
| `/subscribe <anime>` | 設定新劇集自動下載 |
| `/status` | 系統概覽（運行時間、磁碟、串流中） |
| `/mylist [status]` | 按狀態篩選的動畫收藏 |
| `/continue` | 最近觀看的動畫及續播連結 |

## 互動功能

指令支援行內按鈕以快速操作：

- **搜尋結果** — 檢視詳情、訂閱或下載的按鈕
- **下載列表** — 暫停、恢復或取消按鈕
- **動畫詳情** — 訂閱、加入收藏或開始播放

<Callout type="info">
Discord 使用斜線指令搭配自動完成。Telegram 使用行內鍵盤和回呼按鈕。
</Callout>

## 推播通知

設定哪些事件會觸發通知：

| 事件 | 說明 |
|---|---|
| 下載開始 | RSS 規則觸發新的下載 |
| 下載完成 | 下載成功完成 |
| 下載失敗 | 下載遇到錯誤 |
| 媒體庫掃描完成 | 媒體庫掃描完成處理 |
| 系統錯誤 | 背景工作意外失敗 |

通知包含豐富嵌入內容（Discord）或格式化訊息（Telegram），附帶動畫封面圖和中繼資料。

## 安全性

<Callout type="warn">
請務必設定**允許的聊天 ID**（Telegram）或**允許的伺服器 ID**（Discord），以限制誰可以與你的機器人互動。若未設定這些限制，任何發現你機器人的人都可以控制你的 milmil 實例。
</Callout>
