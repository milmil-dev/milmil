## 概覽

milmil 會自動記錄你睇過嘅每一集，包括時間戳同播放進度。歷史頁面提供可搜尋、可篩選嘅完整觀看記錄。

## 瀏覽歷史

劇集以網格佈局顯示，包含：

- 附有進度條覆蓋嘅劇集縮圖
- 動畫標題同集數
- 最後觀看時間
- 完成狀態

網格使用**無限滾動**分頁 — 向下捲動時會自動載入更舊嘅記錄。

## 篩選同搜尋

用篩選列縮窄你嘅歷史記錄：

| 篩選條件 | 說明 |
|--------|-------------|
| **全部** | 所有睇過嘅劇集 |
| **追緊** | 正在追嘅動畫 |
| **已完成** | 已經睇完嘅動畫 |
| **已棄追** | 停止觀看嘅動畫 |

你亦可以透過動畫標題搜尋，快速搵到特定作品。

<Callout type="info">
篩選同搜尋可以配合使用 — 結合狀態篩選同標題搜尋，精確搵到你想要嘅記錄。
</Callout>

## 批次操作

開啟**批次模式**就可以一次揀選多個歷史記錄。

<Steps>
<Step>
### 啟用批次模式

喺工具列點擊批次模式切換按鈕，進入多選模式。
</Step>
<Step>
### 揀選記錄

點擊個別記錄進行選取，或者用全選嚟揀選所有可見記錄。
</Step>
<Step>
### 執行操作

揀選一個操作 — **清除已選**會重設所選記錄嘅進度，**刪除**則會將佢哋從歷史中完全移除。
</Step>
</Steps>

<Callout type="warn">
刪除歷史記錄係永久性嘅，無法復原。
</Callout>
