## 播放模式

milmil 支援三種串流模式，自動選擇最佳方案：

### 直接播放

直接提供原始檔案，支援位元組範圍請求。零轉碼開銷 — 最佳畫質同效能。

### 容器轉封裝

即時將 MKV 容器轉封裝為 MP4，唔需要重新編碼視訊或音訊。咁樣喺原生唔支援 MKV 嘅瀏覽器入面都可以播放。

### HLS 轉碼

當來源格式唔相容瀏覽器嗰陣，用 FFmpeg 進行完整嘅 HLS（HTTP 直播串流）轉碼。包含：

- 自適應位元率串流
- 基於工作階段嘅快取，實現快速拖曳
- 可設定嘅畫質預設

## 彈幕（彈幕評論）

即時彈幕疊加喺視訊上，資料來自 DandanPlay。評論喺播放時從螢幕上捲過，營造共同睇嘅體驗。

喺播放器設定入面設定彈幕密度、透明度同字型大小。

## 字幕

milmil 支援：

- **內嵌字幕** — 從 MKV/MP4 容器入面擷取（ASS、SRT 等）
- **外掛字幕** — 視訊旁邊嘅 `.srt`、`.ass`、`.vtt` 檔案
- 多字幕軌道，支援語言選擇

## 觀看進度

你嘅觀看進度會自動儲存同同步：

- 喺任何裝置上從上次睇嘅位置繼續
- 首頁顯示繼續睇區域
- 同 Bangumi 同 AniList 同步進度（連接後）
