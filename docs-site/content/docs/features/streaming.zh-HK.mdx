## 播放模式

milmil 支援三種串流模式，自動選擇最佳方案：

### 直接播放

直接提供原始檔案，支援位元組範圍請求。零轉碼開銷 — 最佳畫質和效能。

### 容器轉封裝

即時將 MKV 容器轉封裝為 MP4，無需重新編碼視訊或音訊。這使得在原生不支援 MKV 的瀏覽器中也能播放。

### HLS 轉碼

當來源格式不相容瀏覽器時，使用 FFmpeg 進行完整的 HLS（HTTP 直播串流）轉碼。包含：

- 自適應位元率串流
- 基於工作階段的快取，實現快速拖曳
- 可設定的畫質預設

## 彈幕（彈幕評論）

即時彈幕疊加在視訊上，資料來自 DandanPlay。評論在播放時從螢幕上捲過，營造共同觀看的體驗。

在播放器設定中設定彈幕密度、透明度和字型大小。

## 字幕

milmil 支援：

- **內嵌字幕** — 從 MKV/MP4 容器中擷取（ASS、SRT 等）
- **外掛字幕** — 視訊旁邊的 `.srt`、`.ass`、`.vtt` 檔案
- 多字幕軌道，支援語言選擇

## 觀看進度

你的觀看進度會自動儲存和同步：

- 在任何裝置上從上次觀看位置繼續
- 首頁顯示繼續觀看區域
- 與 Bangumi 和 AniList 同步進度（連接後）
