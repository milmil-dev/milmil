## 개요

milmil은 시청하는 모든 에피소드의 타임스탬프와 재생 진행률을 자동으로 기록합니다. 기록 페이지에서는 시청한 모든 콘텐츠를 검색하고 필터링할 수 있는 뷰를 제공합니다.

## 기록 탐색

에피소드는 다음 정보를 표시하는 그리드 레이아웃으로 나타납니다:

- 진행률 바가 오버레이된 에피소드 썸네일
- 애니메이션 제목 및 에피소드 번호
- 마지막 시청 시간
- 시청 완료 상태

그리드는 **무한 스크롤** 페이지네이션을 사용하며, 아래로 스크롤하면 이전 항목이 자동으로 로드됩니다.

## 필터링 및 검색

필터 바를 사용하여 기록을 좁힐 수 있습니다:

| 필터 | 설명 |
|--------|-------------|
| **전체** | 시청한 모든 에피소드 |
| **시청 중** | 현재 시청 중인 애니메이션 |
| **완료** | 시청 완료한 애니메이션 |
| **중단** | 시청을 중단한 애니메이션 |

애니메이션 제목으로 검색하여 특정 작품을 빠르게 찾을 수도 있습니다.

<Callout type="info">
필터와 검색은 함께 작동합니다 — 상태 필터와 제목 검색을 조합하여 원하는 항목을 정확하게 찾을 수 있습니다.
</Callout>

## 일괄 작업

**일괄 모드**를 활성화하여 여러 기록 항목을 한 번에 선택할 수 있습니다.

<Steps>
<Step>
### 일괄 모드 활성화

도구 모음에서 일괄 모드 토글을 클릭하여 다중 선택 모드로 전환합니다.
</Step>
<Step>
### 항목 선택

개별 항목을 클릭하여 선택하거나, 전체 선택을 사용하여 표시된 모든 항목을 선택합니다.
</Step>
<Step>
### 작업 적용

작업을 선택합니다 — **선택 항목 초기화**는 선택된 항목의 진행률을 초기화하고, **삭제**는 기록에서 완전히 제거합니다.
</Step>
</Steps>

<Callout type="warn">
기록 항목 삭제는 영구적이며 되돌릴 수 없습니다.
</Callout>
