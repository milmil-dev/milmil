## 概览

设置页面按标签面板组织，每个面板涵盖不同的配置领域。可从侧边栏或导航菜单打开。

## 面板

### 通用

设置你偏好的**显示语言**（EN、JA、ZH-CN、ZH-TW、ZH-HK、KO），选择日历视图的**每周起始日**，以及切换**自动添加到收藏**，使新匹配的动画自动添加到你的收藏中。

### 播放器

自定义字幕外观 — **字体大小**、**字体**和**样式预设** — 并查看播放控制的默认**键盘快捷键**（播放/暂停、快进快退、音量、全屏等）。

### 账户

管理你的**用户名**，生成或撤销用于第三方访问的 **API 令牌**，以及查看或终止活跃**会话**。

### 集成

连接外部服务：

| 服务 | 详情 |
|---------|---------|
| **DandanPlay** | 文件哈希匹配和弹幕 |
| **Trakt.tv** | 通过 OAuth 设备码流程同步观看历史 |

<Callout type="info">
Trakt.tv 使用设备码流程 — milmil 会显示一个代码，你需要在任意浏览器访问 trakt.tv/activate 并输入该代码。
</Callout>

### 下载

查看当前**下载引擎状态**，并运行**健康检查**以验证种子客户端和订阅源是否正常运行。

### 通知

按事件类型配置**推送**和**邮件**通知偏好（如新剧集可用、下载完成、扫描完成等）。

### 备份

设置自动备份到 **WebDAV** 或 **S3 兼容**存储。设置备份频率和保留策略，以保护你的数据库和配置。

<Callout type="warn">
备份包含你的数据库和设置，但不包含媒体文件。请确保你的媒体存储有自己的冗余方案。
</Callout>

### 存储

查看所有已配置后端的**缓存统计**和**存储使用情况**。使用**清除缓存**操作回收缩略图和临时文件占用的磁盘空间。

### 关于

显示当前**应用版本**、开源**许可证**和项目**致谢**。
