## 개요

milmil의 비디오 플레이어는 커스텀 다크 테마와 모듈식 플러그인 시스템을 갖춘 VideoJS 기반으로 제작되었습니다. HLS 스트리밍, 실시간 MKV-MP4 컨테이너 리먹싱, 직접 스트림 URL을 지원합니다.

## 플러그인 시스템

플레이어는 각각 특정 기능을 담당하는 내장 플러그인 세트로 확장됩니다.

### 재생 플러그인

- 재생 속도 조절 (0.25x–4x)
- 다음 에피소드 자동 재생
- 특정 구간 반복을 위한 A-B 루프
- 인트로/아웃트로 건너뛰기

### 자막 플러그인

- 다중 자막 트랙 선택 (내장 및 외부)
- 스타일 커스터마이징 — 글꼴, 크기, 색상, 외곽선, 위치 조정
- `.srt`, `.ass`, `.vtt` 파일을 드래그 앤 드롭하여 즉시 자막 로드

### 키보드 플러그인

- 모든 플레이어 동작에 대한 완전한 키 바인딩 커스터마이징
- `?`를 눌러 키보드 단축키 도움말 오버레이 열기

### 미디어 설정 플러그인

- 이퀄라이저 프리셋이 포함된 오디오 인핸서
- 비디오 필터 — 밝기, 대비, 채도, 색조 조정

### 제스처 플러그인

- 탭으로 재생/일시정지, 더블 탭으로 탐색
- 모바일에서 위/아래 스와이프로 볼륨 및 밝기 조절
- 길게 누르기로 빨리 감기

### 캡처 플러그인

- 현재 프레임을 PNG로 스크린샷
- 설정 가능한 길이로 애니메이션 GIF 클립 녹화

## 탄막 오버레이

DandanPlay에서 가져온 실시간 탄막 코멘트가 재생 중 비디오 위를 스크롤합니다. 밀도, 불투명도, 글꼴 크기, 표시 영역 모두 플레이어 내에서 설정할 수 있습니다.

<Callout type="info">
탄막 기능을 사용하려면 DandanPlay 연동이 활성화되어 있어야 합니다. [연동 설정](/docs/configuration/integrations)을 참조하세요.
</Callout>

## 에피소드 사이드바

접을 수 있는 사이드바에 현재 애니메이션의 모든 에피소드가 표시됩니다. 목록 뷰와 그리드 뷰 간 전환이 가능하며, 플레이어를 떠나지 않고 원하는 에피소드로 이동할 수 있습니다.

## 관련 추천

플레이어 아래에 장르, 태그, 프랜차이즈 관계를 기반으로 관련 애니메이션을 표시합니다 — 후속작, 스핀오프, 유사 작품을 발견하는 데 유용합니다.

## 기술 정보 팝오버

정보 아이콘을 클릭하면 현재 스트림의 기술 세부사항을 확인할 수 있습니다: 비디오 해상도, 코덱, 비트레이트, 컨테이너 형식, 사용 가능한 오디오 트랙 등.

## 시청 진행률

재생 위치는 몇 초마다 자동으로 저장됩니다. 다시 돌아오면 마지막 위치에서 정확하게 재생이 재개됩니다. Bangumi 및 AniList 연동이 설정된 경우 진행률이 동기화됩니다.
