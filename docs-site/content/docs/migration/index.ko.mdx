<Callout type="info">
milmil에는 아직 자동 마이그레이션 도구가 없습니다. 아래 가이드에서는 수동으로 이전할 수 있는 항목과 다시 설정이 필요한 항목을 설명합니다.
</Callout>

<Tabs items={["From Jellyfin", "From Plex", "From Seanime"]}>
<Tab value="From Jellyfin">

## Jellyfin에서 마이그레이션

### 이전 가능한 항목
- **미디어 파일** — milmil에서 같은 미디어 디렉토리를 가리키세요. 파일을 이동할 필요가 없습니다.
- **파일 구조** — milmil은 동일한 폴더별 시리즈 구조를 지원합니다.

### 다시 설정이 필요한 항목
- **메타데이터** — milmil은 다른 메타데이터 제공업체를 사용합니다 (TheTVDB/TMDb 대신 Bangumi, AniList, DandanPlay). 첫 번째 스캔 시 모든 메타데이터가 다시 매칭됩니다.
- **시청 기록** — 이전할 수 없습니다. 새로 시작하거나 시청한 에피소드를 수동으로 표시하세요.
- **사용자 계정** — milmil에서 새 계정을 생성하세요.

<Callout type="warn">
milmil의 메타데이터 매칭은 애니메이션에 특화되어 있습니다. Jellyfin에서 매칭이 어려웠던 작품도 DandanPlay와 Bangumi 같은 애니메이션 전용 제공업체 덕분에 milmil에서 더 정확하게 매칭될 수 있습니다.
</Callout>

### 단계

<Steps>
<Step>
Jellyfin과 함께 milmil을 설치합니다 (공존 가능).
</Step>
<Step>
Jellyfin이 사용하는 동일한 미디어 디렉토리를 milmil에서 가리킵니다.
</Step>
<Step>
milmil에서 전체 라이브러리 스캔을 실행합니다.
</Step>
<Step>
메타데이터 매칭을 확인하고 잘못된 매칭을 수동으로 수정합니다.
</Step>
<Step>
컬렉션 동기화를 원하면 Bangumi/AniList를 연결합니다.
</Step>
</Steps>

## Plex에서 마이그레이션

### 이전 가능한 항목
- **미디어 파일** — milmil에서 같은 미디어 디렉토리를 가리키세요.

### 다시 설정이 필요한 항목
- **메타데이터** — 애니메이션 전용 제공업체에서 모두 다시 매칭됩니다.
- **시청 기록** — 이전할 수 없습니다.
- **재생 목록/컬렉션** — 이전할 수 없습니다.
- **사용자 계정** — 새 계정을 생성하세요.

### 단계

<Steps>
<Step>
Plex와 함께 milmil을 설치합니다.
</Step>
<Step>
동일한 미디어 라이브러리 경로를 milmil에서 가리킵니다.
</Step>
<Step>
전체 라이브러리 스캔을 실행합니다.
</Step>
<Step>
메타데이터 매칭을 검토하고 수정합니다.
</Step>
</Steps>

## Seanime에서 마이그레이션

### 이전 가능한 항목
- **미디어 파일** — 동일한 디렉토리 구조.
- **AniList 데이터** — Seanime에서 AniList를 사용했다면, milmil에서 동일한 AniList 계정을 연결하여 컬렉션을 동기화할 수 있습니다.

### 다시 설정이 필요한 항목
- **로컬 메타데이터** — 다시 스캔하고 다시 매칭합니다.
- **다운로드 규칙** — RSS 구독을 다시 생성해야 합니다.
- **설정** — 모든 애플리케이션 설정.

### 단계

<Steps>
<Step>
milmil을 설치하고 애니메이션 디렉토리를 가리킵니다.
</Step>
<Step>
AniList 계정을 연결하여 컬렉션 데이터를 복구합니다.
</Step>
<Step>
전체 라이브러리 스캔을 실행합니다.
</Step>
<Step>
RSS 구독이나 다운로드 규칙을 다시 생성합니다.
</Step>
</Steps>
