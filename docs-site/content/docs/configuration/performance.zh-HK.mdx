## Redis 快取

<Callout type="info">
Redis 係選用嘅，但強烈建議喺正式環境使用。無 Redis 嘅話，milmil 會用記憶體內快取，重啟後唔會保留。
</Callout>

```bash
REDIS_URL=redis://localhost:6379
```

### 容量建議

| 媒體庫大小 | 建議 Redis 記憶體 |
|---|---|
| < 500 部動畫 | 64 MB |
| 500–2000 部動畫 | 256 MB |
| 2000+ 部動畫 | 512 MB+ |

## 轉碼

### 硬件加速

<Callout type="warn">
硬件加速可以大幅降低轉碼時嘅 CPU 使用率。無硬件加速嘅話，單一 1080p 轉碼串流可以用盡一個 CPU 核心嘅 100%。
</Callout>

milmil 支援 FFmpeg 硬件加速後端：

| 後端 | 說明 |
|---|---|
| **VAAPI** | Video Acceleration API（Linux 上嘅 Intel、AMD） |
| **NVENC** | NVIDIA GPU 編碼 |
| **QSV** | Intel Quick Sync Video |
| **VideoToolbox** | macOS 硬件加速 |

Docker 環境下需要透傳 GPU 裝置：

```yaml
# NVIDIA
devices:
  - /dev/nvidia0:/dev/nvidia0
  - /dev/nvidiactl:/dev/nvidiactl

# Intel VAAPI
devices:
  - /dev/dri:/dev/dri
```

### 品質預設

| 預設 | 使用場景 | CPU 使用率 |
|---|---|---|
| `ultrafast` | 低功耗裝置（RPi） | 最低 |
| `fast` | 品質/速度平衡 | 中等 |
| `medium` | 預設 — 良好品質 | 高 |

## 資料庫調校

<Tabs items={["PostgreSQL", "SQLite"]}>
<Tab value="PostgreSQL">

大型媒體庫建議調校 PostgreSQL：

```sql
-- 連線池（喺 DATABASE_URL 設定）
-- ?pool_max_conns=20&pool_min_conns=5

-- 建議嘅 postgresql.conf 調整
shared_buffers = 256MB
effective_cache_size = 1GB
work_mem = 16MB
```

</Tab>
<Tab value="SQLite">

SQLite 適用於中小型媒體庫。啟用 WAL 模式可以改善併發讀取效能（milmil 會自動啟用）：

```sql
PRAGMA journal_mode=WAL;
PRAGMA busy_timeout=5000;
```

<Callout type="warn">
SQLite 嘅寫入併發能力有限。如果你經常同時執行掃描或下載，建議轉用 PostgreSQL。
</Callout>

</Tab>
</Tabs>
