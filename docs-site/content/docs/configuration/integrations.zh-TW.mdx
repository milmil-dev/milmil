## Bangumi

[Bangumi](https://bangumi.tv) 提供動畫中繼資料、評分和收藏同步。

### 設定

1. 前往 **設定 > 整合**
2. 點選 **連接 Bangumi**
3. 在 Bangumi OAuth 流程中授權 milmil
4. 你的收藏將自動同步

### 功能

- 動畫中繼資料（標題、簡介、評分、集數）
- 觀看狀態同步（計劃看、在看、看過等）
- 評分同步

## AniList

[AniList](https://anilist.co) 是一個替代的中繼資料和追蹤服務。

### 設定

1. 前往 **設定 > 整合**
2. 點選 **連接 AniList**
3. 在 AniList OAuth 流程中授權 milmil

### 功能

- 動畫中繼資料和封面圖片
- 觀看進度同步
- 評分同步

## DandanPlay

[弹弹play开放弹幕网络（DandanPlay）](https://www.dandanplay.com) 提供基於檔案雜湊的比對和彈幕。其開發者協議要求以完整名稱標註來源，且未經書面授權不得商用；milmil 會在播放器與設定頁標註。

### 設定

在開發者中心（`dev.dandanplay.com`）註冊應用並依實際部署選擇專案類型（憑證按應用分層與配額管理），然後設定環境變數：

```bash
DANDANPLAY_APP_ID=your_app_id
DANDANPLAY_APP_SECRET=your_app_secret
```

### 功能

- 檔案雜湊比對 — 最精確的劇集識別
- 播放時彈幕疊加
- 劇集中繼資料

## TMDB

[TMDB](https://www.themoviedb.org) 用作交叉參照電視節目中繼資料的備援來源，也會依介面語言補充本地化劇集中繼資料。此整合為選用；在設定 > 整合填入 TMDB API Read Access Token（建議）或 v3 API key 後啟用。

TMDB 中繼資料語言會跟隨設定 > 一般中的介面語言；未設定時預設回退到繁體中文。
