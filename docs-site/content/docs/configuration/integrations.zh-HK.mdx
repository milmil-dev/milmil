## Bangumi

[Bangumi](https://bangumi.tv) 提供動畫中繼資料、評分同埋收藏同步。

### 設定

1. 前往 **設定 > 整合**
2. 撳 **連接 Bangumi**
3. 喺 Bangumi OAuth 流程入面授權 milmil
4. 你嘅收藏將會自動同步

### 功能

- 動畫中繼資料（標題、簡介、評分、集數）
- 觀看狀態同步（計劃看、在看、看過等）
- 評分同步

## AniList

[AniList](https://anilist.co) 係一個替代嘅中繼資料同埋追蹤服務。

### 設定

1. 前往 **設定 > 整合**
2. 撳 **連接 AniList**
3. 喺 AniList OAuth 流程入面授權 milmil

### 功能

- 動畫中繼資料同封面圖片
- 觀看進度同步
- 評分同步

## DandanPlay

[DandanPlay](https://www.dandanplay.com) 提供基於檔案雜湊嘅比對同彈幕（彈幕評論）。

### 設定

喺 DandanPlay 開發者入口網站註冊 API 憑證，然後設定環境變數：

```bash
DANDANPLAY_APP_ID=your_app_id
DANDANPLAY_APP_SECRET=your_app_secret
```

### 功能

- 檔案雜湊比對 — 最精確嘅劇集識別
- 播放時彈幕疊加
- 劇集中繼資料

## TMDB

[TMDB](https://www.themoviedb.org) 用作交叉參照電視節目中繼資料嘅備援來源。唔需要設定。
