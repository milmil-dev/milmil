## Redis キャッシュ

<Callout type="info">
Redis はオプションですが、本番環境では強く推奨されます。Redis がない場合、milmil は再起動時に保持されないインメモリキャッシュを使用します。
</Callout>

```bash
REDIS_URL=redis://localhost:6379
```

### サイジング推奨

| ライブラリサイズ | 推奨 Redis メモリ |
|---|---|
| < 500 アニメ | 64 MB |
| 500〜2000 アニメ | 256 MB |
| 2000+ アニメ | 512 MB+ |

## トランスコーディング

### ハードウェアアクセラレーション

<Callout type="warn">
ハードウェアアクセラレーションにより、トランスコーディング時の CPU 使用率が大幅に削減されます。これがないと、単一の 1080p トランスコードストリームで CPU コア 1 つを 100% 使用する可能性があります。
</Callout>

milmil は FFmpeg ハードウェアアクセラレーションバックエンドに対応しています：

| バックエンド | 説明 |
|---|---|
| **VAAPI** | Video Acceleration API（Linux 上の Intel、AMD） |
| **NVENC** | NVIDIA GPU エンコーディング |
| **QSV** | Intel Quick Sync Video |
| **VideoToolbox** | macOS ハードウェアアクセラレーション |

Docker では GPU デバイスをパススルーします：

```yaml
# NVIDIA
devices:
  - /dev/nvidia0:/dev/nvidia0
  - /dev/nvidiactl:/dev/nvidiactl

# Intel VAAPI
devices:
  - /dev/dri:/dev/dri
```

### 品質プリセット

| プリセット | ユースケース | CPU 使用率 |
|---|---|---|
| `ultrafast` | 低電力デバイス（RPi） | 最小 |
| `fast` | 品質と速度のバランス | 中程度 |
| `medium` | デフォルト — 高品質 | 高 |

## データベースチューニング

<Tabs items={["PostgreSQL", "SQLite"]}>
<Tab value="PostgreSQL">

大規模ライブラリでは PostgreSQL をチューニングします：

```sql
-- コネクションプール（DATABASE_URL で設定）
-- ?pool_max_conns=20&pool_min_conns=5

-- 推奨 postgresql.conf 設定
shared_buffers = 256MB
effective_cache_size = 1GB
work_mem = 16MB
```

</Tab>
<Tab value="SQLite">

SQLite は小〜中規模のライブラリに適しています。WAL モードを有効にすると同時読み取りパフォーマンスが向上します（milmil は自動的にこれを有効にします）：

```sql
PRAGMA journal_mode=WAL;
PRAGMA busy_timeout=5000;
```

<Callout type="warn">
SQLite は書き込みの同時実行性が限られています。頻繁なスキャンやダウンロードを同時に実行する場合は、PostgreSQL への切り替えを検討してください。
</Callout>

</Tab>
</Tabs>
