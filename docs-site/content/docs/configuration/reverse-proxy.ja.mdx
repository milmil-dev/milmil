title: リバースプロキシ

<Callout type="info">
リバースプロキシは HTTPS に必須であり、本番デプロイでは推奨されます。milmil はリアルタイム機能（弾幕、通知）に WebSocket 接続を使用するため、プロキシは WebSocket アップグレードに対応している必要があります。
</Callout>

<Tabs items={["Nginx", "Caddy", "Traefik"]}>
<Tab value="Nginx">

## Nginx

```nginx
server {
    listen 443 ssl http2;
    server_name milmil.example.com;

    ssl_certificate /etc/letsencrypt/live/milmil.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/milmil.example.com/privkey.pem;

    # フロントエンド
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # API + WebSocket
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket エンドポイント
    location /ws {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # ストリーミング — タイムアウトを延長しバッファリングを無効化
    location /api/v1/stream/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_buffering off;
        proxy_request_buffering off;
        client_max_body_size 0;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }
}

# HTTP から HTTPS へのリダイレクト
server {
    listen 80;
    server_name milmil.example.com;
    return 301 https://$host$request_uri;
}
```

<Callout type="warn">
ストリーミングのロケーションブロックではバッファリングを無効にし、タイムアウトを延長しています。これがないと、大きな動画ファイルのストリーミングが失敗する場合があります。
</Callout>

### Let's Encrypt と Certbot

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d milmil.example.com
```

## Caddy

Caddy は Let's Encrypt による自動 HTTPS を提供します。

```
milmil.example.com {
    handle /api/* {
        reverse_proxy localhost:8080
    }

    handle /ws {
        reverse_proxy localhost:8080
    }

    handle {
        reverse_proxy localhost:3000
    }
}
```

<Callout type="info">
Caddy は HTTPS 証明書を自動的に処理します — 追加の設定は不要です。DNS をサーバーに向けるだけです。
</Callout>

## Traefik

`docker-compose.yml` にラベルを追加します：

```yaml
services:
  milmil-web:
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.milmil.rule=Host(`milmil.example.com`)"
      - "traefik.http.routers.milmil.tls.certresolver=letsencrypt"
      - "traefik.http.services.milmil.loadbalancer.server.port=3000"

  milmil-api:
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.milmil-api.rule=Host(`milmil.example.com`) && (PathPrefix(`/api`) || PathPrefix(`/ws`))"
      - "traefik.http.routers.milmil-api.tls.certresolver=letsencrypt"
      - "traefik.http.services.milmil-api.loadbalancer.server.port=8080"
```

## トラブルシューティング

<Accordions>
<Accordion title="WebSocket 接続が失敗する（弾幕が読み込まれない）">
プロキシが `/ws` と `/api/` パスの `Upgrade` と `Connection` ヘッダーを転送していることを確認してください。Nginx では `proxy_http_version 1.1` が設定されているか確認してください。
</Accordion>
<Accordion title="動画ストリーミングが途切れる・遅い">
ストリーミングエンドポイントのプロキシバッファリングを無効にしてください。Nginx では `proxy_buffering off` を設定し、`proxy_read_timeout` を延長してください。
</Accordion>
<Accordion title="502 Bad Gateway">
`milmil-api`（ポート 8080）と `milmil-web`（ポート 3000）の両方が実行中であることを確認してください。`docker ps` で確認できます。
</Accordion>
</Accordions>
