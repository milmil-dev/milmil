<Callout type="info">
正式環境部署需要反向代理嚟提供 HTTPS，亦係推薦做法。milmil 使用 WebSocket 連線嚟實現即時功能（彈幕、通知），所以你嘅代理必須支援 WebSocket 升級。
</Callout>

<Tabs items={["Nginx", "Caddy", "Traefik"]}>
<Tab value="Nginx">

## Nginx

```nginx
server {
    listen 443 ssl http2;
    server_name milmil.example.com;

    ssl_certificate /etc/letsencrypt/live/milmil.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/milmil.example.com/privkey.pem;

    # 前端
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # API + WebSocket
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket 端點
    location /ws {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # 串流 — 增加逾時並停用緩衝
    location /api/v1/stream/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_buffering off;
        proxy_request_buffering off;
        client_max_body_size 0;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }
}

# HTTP 重新導向到 HTTPS
server {
    listen 80;
    server_name milmil.example.com;
    return 301 https://$host$request_uri;
}
```

<Callout type="warn">
串流嘅 location 區塊停用咗緩衝並增加咗逾時。無呢個設定嘅話，大型影片檔案可能無法正常串流。
</Callout>

### 用 Certbot 設定 Let's Encrypt

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d milmil.example.com
```

## Caddy

Caddy 提供自動嘅 Let's Encrypt HTTPS。

```
milmil.example.com {
    handle /api/* {
        reverse_proxy localhost:8080
    }

    handle /ws {
        reverse_proxy localhost:8080
    }

    handle {
        reverse_proxy localhost:3000
    }
}
```

<Callout type="info">
Caddy 會自動處理 HTTPS 憑證 — 唔使額外設定。只需要將 DNS 指向你嘅伺服器就得。
</Callout>

## Traefik

喺你嘅 `docker-compose.yml` 加入標籤：

```yaml
services:
  milmil-web:
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.milmil.rule=Host(`milmil.example.com`)"
      - "traefik.http.routers.milmil.tls.certresolver=letsencrypt"
      - "traefik.http.services.milmil.loadbalancer.server.port=3000"

  milmil-api:
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.milmil-api.rule=Host(`milmil.example.com`) && (PathPrefix(`/api`) || PathPrefix(`/ws`))"
      - "traefik.http.routers.milmil-api.tls.certresolver=letsencrypt"
      - "traefik.http.services.milmil-api.loadbalancer.server.port=8080"
```

## 疑難排解

<Accordions>
<Accordion title="WebSocket 連線失敗（彈幕無法載入）">
確保你嘅代理為 `/ws` 同 `/api/` 路徑傳遞咗 `Upgrade` 同 `Connection` 標頭。檢查 Nginx 有無設定 `proxy_http_version 1.1`。
</Accordion>
<Accordion title="影片串流中斷或速度慢">
為串流端點停用代理緩衝。喺 Nginx 設定 `proxy_buffering off` 並增加 `proxy_read_timeout`。
</Accordion>
<Accordion title="502 Bad Gateway">
檢查 `milmil-api`（連接埠 8080）同 `milmil-web`（連接埠 3000）係咪正常運行。用 `docker ps` 驗證。
</Accordion>
</Accordions>
