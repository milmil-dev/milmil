title: 재생 문제
description: 스트리밍, 트랜스코딩, 탄막 문제를 해결합니다.
---

<Accordions>
<Accordion title="비디오가 재생되지 않음 / 검은 화면">
**원인:** 비디오 코덱이 브라우저에서 다이렉트 플레이를 지원하지 않습니다.

**해결 방법:**
1. 라이브러리 파일 브라우저에서 파일의 코덱을 확인하세요 (예: HEVC, AV1)
2. milmil은 자동으로 리먹싱 또는 트랜스코딩으로 전환됩니다 — FFmpeg가 설치되어 있고 접근 가능한지 확인하세요
3. 다른 브라우저를 사용해 보세요 (Chrome이 가장 넓은 코덱 지원을 제공합니다)
</Accordion>

<Accordion title="트랜스코딩이 매우 느림">
**원인:** 소프트웨어 트랜스코딩은 CPU를 사용하며, HD/4K 콘텐츠에서는 느립니다.

**해결 방법:**
1. 하드웨어 가속을 활성화하세요 — [성능 튜닝](/docs/configuration/performance) 참조
2. 저전력 장치에서는 `ultrafast` 또는 `fast` 프리셋을 사용하세요
3. 다이렉트 플레이(트랜스코딩 불필요)를 위해 파일을 H.264 MP4로 사전 인코딩하세요
</Accordion>

<Accordion title="탄막(탄막 코멘트)이 표시되지 않음">
**원인:** DandanPlay 연동이 설정되지 않았거나 해당 에피소드에 코멘트가 없습니다.

**해결 방법:**
1. DandanPlay 자격 증명이 설정되어 있는지 확인하세요 — [통합 설정](/docs/configuration/integrations) 참조
2. 에피소드가 DandanPlay를 통해 매칭되었는지 확인하세요 (파일 해시 매칭)
3. 일부 에피소드는 코멘트가 적거나 없을 수 있습니다
4. 리버스 프록시 뒤에 있는 경우 WebSocket 연결이 작동하는지 확인하세요 — [리버스 프록시](/docs/configuration/reverse-proxy) 참조
</Accordion>

<Accordion title="자막이 표시되지 않음">
**해결 방법:**
1. 플레이어 컨트롤에서 자막 트랙이 선택되어 있는지 확인하세요
2. 내장 자막의 경우 milmil이 MKV/MP4 컨테이너에서 자동으로 추출합니다
3. 외부 자막의 경우 `.srt`/`.ass`/`.vtt` 파일이 동일한 디렉토리에 동일한 기본 파일명으로 있는지 확인하세요
4. 복잡한 스타일링이 적용된 ASS 자막은 웹 플레이어에서 완벽하게 렌더링되지 않을 수 있습니다
</Accordion>

<Accordion title="비디오 버퍼링 / 탐색이 느림">
**해결 방법:**
1. HLS 트랜스코딩을 사용하는 경우, 이전에 탐색한 세그먼트는 캐시됩니다 — 이후 탐색은 더 빨라집니다
2. 서버와 클라이언트 간의 네트워크 대역폭을 확인하세요
3. 원격 접근의 경우 리버스 프록시가 스트림을 버퍼링하지 않는지 확인하세요 — [리버스 프록시](/docs/configuration/reverse-proxy) 참조
</Accordion>
</Accordions>
