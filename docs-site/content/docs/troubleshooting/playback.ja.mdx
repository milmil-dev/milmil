---
title: 再生の問題
description: ストリーミング、トランスコーディング、弾幕の問題のトラブルシューティング。
---

<Accordions>
<Accordion title="動画が再生されない / 画面が真っ黒">
**原因：** 動画のコーデックがブラウザのダイレクトプレイに対応していない。

**解決方法：**
1. ライブラリのファイルブラウザでファイルのコーデックを確認（例：HEVC、AV1）
2. milmil は自動的にリミックスまたはトランスコードにフォールバックします — FFmpeg がインストールされアクセス可能であることを確認してください
3. 別のブラウザを試してください（Chrome が最も広いコーデックサポートを持っています）
</Accordion>

<Accordion title="トランスコーディングが非常に遅い">
**原因：** ソフトウェアトランスコーディングは CPU を使用するため、HD/4K コンテンツでは低速です。

**解決方法：**
1. ハードウェアアクセラレーションを有効にする — [パフォーマンスチューニング](/docs/configuration/performance) を参照
2. 低電力デバイスには `ultrafast` または `fast` プリセットを使用
3. ダイレクトプレイ用にファイルを H.264 MP4 に事前エンコード（トランスコーディング不要）
</Accordion>

<Accordion title="弾幕（コメント）が表示されない">
**原因：** DandanPlay 連携が設定されていないか、このエピソードにコメントがない。

**解決方法：**
1. DandanPlay の認証情報が設定されていることを確認 — [連携設定](/docs/configuration/integrations) を参照
2. エピソードが DandanPlay 経由でマッチングされていることを確認（ファイルハッシュマッチ）
3. 一部のエピソードではコメントが少ないか、ない場合があります
4. リバースプロキシの背後にいる場合、WebSocket 接続が機能していることを確認 — [リバースプロキシ](/docs/configuration/reverse-proxy) を参照
</Accordion>

<Accordion title="字幕が表示されない">
**解決方法：**
1. プレイヤーコントロールで字幕トラックが選択されていることを確認
2. 埋め込み字幕の場合、milmil は MKV/MP4 コンテナから自動的に抽出します
3. 外部字幕の場合、`.srt`/`.ass`/`.vtt` ファイルが動画と同じディレクトリに同じベースファイル名で配置されていることを確認
4. 複雑なスタイリングを持つ ASS 字幕は Web プレイヤーで完全にはレンダリングされない場合があります
</Accordion>

<Accordion title="動画のバッファリング / シークが遅い">
**解決方法：**
1. HLS トランスコーディングを使用している場合、以前にシークしたセグメントはキャッシュされます — 後続のシークはより高速になります
2. サーバーとクライアント間のネットワーク帯域幅を確認
3. リモートアクセスの場合、リバースプロキシがストリームをバッファリングしていないことを確認 — [リバースプロキシ](/docs/configuration/reverse-proxy) を参照
</Accordion>
</Accordions>
