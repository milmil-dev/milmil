## 一般問題

<Accordions>
<Accordion title="最低系統需求係乜嘢？">
- **CPU：** 2 核心（轉碼建議 4 核心以上）
- **RAM：** 最低 1 GB，建議 2 GB+
- **儲存空間：** 視乎你嘅媒體庫大小。milmil 本身應用程式同資料庫用少過 500 MB。
- **FFmpeg：** 媒體資訊擷取同轉碼必需
</Accordion>
<Accordion title="milmil 支唔支援多用戶？">
支援。喺 **設定 > 用戶** 建立額外嘅用戶帳號。每個用戶有自己嘅收藏、觀看進度同偏好設定。
</Accordion>
<Accordion title="可唔可以喺外網存取 milmil？">
可以，但需要設定反向代理同 HTTPS。參閱[反向代理](/docs/configuration/reverse-proxy)指南。唔好喺無 HTTPS 嘅情況下直接將 milmil 暴露喺互聯網上。
</Accordion>
<Accordion title="支援邊啲影片格式？">
milmil 可以播放任何 FFmpeg 支援嘅格式。直接播放需要瀏覽器支援該編解碼器（通常係 MP4 入面嘅 H.264/H.265）。其他格式會自動重新封裝或轉碼。
</Accordion>
<Accordion title="點樣更新 milmil？">
拉取最新嘅 Docker 映像檔並重新啟動：

```bash
docker compose pull
docker compose up -d
```

資料庫遷移會喺啟動時自動套用。
</Accordion>
</Accordions>
