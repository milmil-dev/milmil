## 일반

<Accordions>
<Accordion title="최소 시스템 요구 사항은 무엇인가요?">
- **CPU:** 2코어 (트랜스코딩 시 4코어 이상 권장)
- **RAM:** 최소 1 GB, 2 GB 이상 권장
- **스토리지:** 미디어 라이브러리에 따라 다릅니다. milmil 자체는 애플리케이션과 데이터베이스에 500 MB 미만을 사용합니다.
- **FFmpeg:** 미디어 정보 추출 및 트랜스코딩에 필요
</Accordion>
<Accordion title="milmil은 다중 사용자를 지원하나요?">
네. **설정 > 사용자**에서 추가 사용자 계정을 생성하세요. 각 사용자는 자체 컬렉션, 시청 기록, 환경 설정을 가집니다.
</Accordion>
<Accordion title="외부 네트워크에서 milmil에 접근할 수 있나요?">
네, 하지만 HTTPS가 적용된 리버스 프록시를 설정해야 합니다. [리버스 프록시](/docs/configuration/reverse-proxy) 가이드를 참조하세요. HTTPS 없이 milmil을 인터넷에 직접 노출하지 마세요.
</Accordion>
<Accordion title="어떤 비디오 형식이 지원되나요?">
milmil은 FFmpeg가 지원하는 모든 형식을 재생할 수 있습니다. 다이렉트 플레이의 경우 브라우저가 코덱을 지원해야 합니다 (일반적으로 MP4의 H.264/H.265). 다른 형식은 자동으로 리먹싱 또는 트랜스코딩됩니다.
</Accordion>
<Accordion title="milmil을 어떻게 업데이트하나요?">
최신 Docker 이미지를 가져오고 재시작하세요:

```bash
docker compose pull
docker compose up -d
```

데이터베이스 마이그레이션은 시작 시 자동으로 적용됩니다.
</Accordion>
</Accordions>
