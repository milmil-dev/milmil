# TanStack SPA Template

A modern React single-page application template with TanStack Router, Tailwind CSS v4, and PWA support.

## Quick Start

```bash
bun install
bun run dev
```

## Features

- **React 19** with React Compiler
- **TanStack Router** — type-safe, code-based routing
- **Tailwind CSS v4** — utility-first styling with OKLCH color scheme
- **Zustand v5** — lightweight global state management
- **TanStack Query v5** — server state and data fetching
- **TanStack Form + Zod** — type-safe forms with validation
- **Lingui v5** — internationalization
- **Serwist** — PWA with service worker
- **Vitest + Testing Library + Playwright** — comprehensive testing
- **Biome** — fast linting and formatting
- **Lefthook + Commitlint** — git hooks and conventional commits

## Scripts

| Command | Description |
|---|---|
| `bun run dev` | Start development server |
| `bun run build` | Production build |
| `bun run check:all` | Run all quality checks |
| `bun run test` | Run unit tests (watch mode) |
| `bun run test:e2e` | Run E2E tests with Playwright |
