## 什么是 milmil？

milmil 是一个自托管的动漫媒体服务器，可以让你管理、发现和串流你的动漫收藏。它将媒体库管理与弹幕、自动下载和多来源元数据匹配等高级功能相结合。

## 核心功能

- **媒体库管理** — 多存储源（本地、SMB、SFTP、40+ 云端后端通过 rclone）自动扫描和元数据匹配
- **串流播放** — 直接播放、容器转封装（MKV 到 MP4）、FFmpeg HLS 转码
- **弹幕** — 来自弹弹Play的实时弹幕叠加
- **自动下载** — 内置种子客户端、RSS 订阅、聚合种子搜索（Nyaa、DMHY、蜜柑等）
- **发现** — 季度日历、热门排行、全文搜索与类型/标签筛选
- **收藏** — 观看状态追踪、个人评分、与 Bangumi 和 AniList 同步
- **多语言** — 完整 i18n 支持英语、日语、韩语、简体中文、繁体中文
- **PWA** — 可安装的渐进式网页应用

## 快速开始

```bash
docker compose up -d
```

然后打开 `http://localhost:3000` 并按照设置向导操作。
