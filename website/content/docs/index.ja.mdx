## milmilとは？

milmilは、アニメコレクションの管理、発見、ストリーミングを可能にするセルフホスト型アニメメディアサーバーです。ライブラリ管理に加え、弾幕（コメント）、自動ダウンロード、マルチプロバイダーメタデータマッチングなどの高度な機能を提供します。

## 主な機能

- **ライブラリ管理** — マルチソースストレージ（ローカル、SMB、SFTP、rclone経由40+クラウドバックエンド）自動スキャンとメタデータマッチング
- **ストリーミング** — ダイレクト再生、コンテナリマックス（MKVからMP4）、FFmpeg HLSトランスコード
- **弾幕** — DandanPlayからのリアルタイム弾幕オーバーレイ
- **自動ダウンロード** — 内蔵トレントクライアント、RSSサブスクリプション、複数プロバイダー横断トレント検索
- **発見** — シーズンカレンダー、トレンドランキング、ジャンル・タグフィルター付きフルテキスト検索
- **コレクション** — 視聴状況追跡、個人評価、BangumiおよびAniListとの同期
- **多言語** — 英語、日本語、韓国語、簡体字中国語、繁体字中国語の完全i18nサポート
- **PWA** — インストール可能なプログレッシブウェブアプリ

## クイックスタート

```bash
docker compose up -d
```

`http://localhost:3000` を開いてセットアップウィザードに従ってください。
