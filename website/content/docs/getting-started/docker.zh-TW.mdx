## 正式環境設定

使用正式環境的 compose 檔案進行完整部署：

```bash
docker compose -f docker-compose.prod.yml up -d
```

### 必要的環境變數

在專案根目錄建立 `.env` 檔案：

```bash
JWT_SECRET=your-secret-key-at-least-32-characters
MILMIL_ENCRYPTION_KEY=your-aes-256-encryption-key
DATABASE_URL=postgres://milmil:password@postgres:5432/milmil?sslmode=disable
```

### 服務

正式環境包含以下服務：

| 服務 | 連接埠 | 說明 |
|---------|------|-------------|
| `milmil-api` | 8080 | Go 後端 API |
| `milmil-web` | 3000 | React 前端 |
| `postgres` | 5432 | PostgreSQL 16 |
| `redis` | 6379 | Redis 7 快取 |

### 反向代理

將 milmil 置於 Nginx 或 Caddy 之後以啟用 HTTPS。Nginx 設定範例：

```nginx
server {
    listen 443 ssl;
    server_name milmil.example.com;

    location / {
        proxy_pass http://localhost:3000;
    }

    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    location /ws {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

### 磁碟區掛載

將媒體目錄對映到容器中：

```yaml
volumes:
  - /path/to/anime:/media/anime
  - milmil-data:/data
```

### 資料庫

- **開發環境**：SQLite（零設定）
- **正式環境**：推薦使用 PostgreSQL 16+
- 啟動時透過 golang-migrate 自動套用遷移
