## セットアップウィザード

milmil を初めて開くと、セットアップウィザードが表示されます：

1. **管理者アカウントの作成** — ユーザー名とパスワードを設定
2. **ライブラリの追加** — アニメメディアディレクトリを指定
3. **ライブラリのスキャン** — milmil がファイルを自動的にスキャンしてマッチング

## ライブラリの追加

milmil は複数のストレージバックエンドに対応しています：

| タイプ | 説明 |
|------|-------------|
| **ローカル** | ホストファイルシステム上のディレクトリ |
| **SMB/CIFS** | Windows ネットワーク共有 |
| **SFTP** | SSH ファイル転送 |
| **WebDAV** | クラウドストレージ（Nextcloud など） |
| **Rclone** | 40 以上のクラウドプロバイダー（Google Drive、OneDrive、Dropbox、S3 など） |

### ローカルディレクトリ

最もシンプルなセットアップ — アニメフォルダのパスを指定するだけです：

```
/media/anime
```

### ネットワークストレージ

SMB、SFTP、または WebDAV の場合、ライブラリ設定で接続情報を入力します。認証情報は AES-256 で暗号化されます。

## メタデータマッチング

スキャン後、milmil は自動的にファイルをアニメエントリにマッチングします：

1. **DandanPlay** — ファイルハッシュマッチング（最も正確）
2. **Bangumi** — タイトルベースのマッチング
3. **AniList** — 代替メタデータソース

マッチしなかったファイルはライブラリ詳細ページから手動でマッチングできます。
