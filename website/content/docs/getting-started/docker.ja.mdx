## 本番環境のセットアップ

本番環境用の compose ファイルで完全なデプロイを行います：

```bash
docker compose -f docker-compose.prod.yml up -d
```

### 必須の環境変数

プロジェクトルートに `.env` ファイルを作成します：

```bash
JWT_SECRET=your-secret-key-at-least-32-characters
MILMIL_ENCRYPTION_KEY=your-aes-256-encryption-key
DATABASE_URL=postgres://milmil:password@postgres:5432/milmil?sslmode=disable
```

### サービス

本番スタックには以下が含まれます：

| サービス | ポート | 説明 |
|---------|------|-------------|
| `milmil-api` | 8080 | Go バックエンド API |
| `milmil-web` | 3000 | React フロントエンド |
| `postgres` | 5432 | PostgreSQL 16 |
| `redis` | 6379 | Redis 7 キャッシュ |

### リバースプロキシ

HTTPS を有効にするため、milmil を Nginx または Caddy の背後に配置します。Nginx の設定例：

```nginx
server {
    listen 443 ssl;
    server_name milmil.example.com;

    location / {
        proxy_pass http://localhost:3000;
    }

    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    location /ws {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

### ボリュームマウント

メディアディレクトリをコンテナにマッピングします：

```yaml
volumes:
  - /path/to/anime:/media/anime
  - milmil-data:/data
```

### データベース

- **開発環境**：SQLite（設定不要）
- **本番環境**：PostgreSQL 16+ を推奨
- 起動時に golang-migrate でマイグレーションが自動適用されます
