## 사전 요구 사항

- **Docker** (권장) 또는 Go 1.26+ 및 Bun 1.3+
- **FFmpeg** — 트랜스코딩 및 미디어 정보 추출에 필요
- **Redis** — 선택 사항이지만 프로덕션 배포 시 권장

## Docker (권장)

Docker Compose로 milmil을 실행하는 것이 가장 간단한 방법입니다:

```bash
git clone https://github.com/milmil-org/milmil.git
cd milmil
docker compose up -d
```

다음 서비스가 모두 시작됩니다:
- **PostgreSQL 16** — 데이터베이스
- **Redis 7** — 캐시
- **milmil-api** — Go 백엔드 (포트 8080)
- **milmil-web** — Nginx를 통한 React 프론트엔드 (포트 3000)

고급 설정은 [Docker 배포](/docs/getting-started/docker)를 참조하세요.

## 수동 설치

### 백엔드 (Go API)

```bash
cd api
go mod download
make build
./server
```

### 프론트엔드 (React SPA)

```bash
cd web
bun install
bun run build
```

`web/dist`의 빌드 결과물을 정적 파일 서버 또는 Nginx로 호스팅합니다.

## 환경 변수

| 변수 | 기본값 | 설명 |
|----------|---------|-------------|
| `DATABASE_URL` | `sqlite://data/milmil.db` | 데이터베이스 연결 문자열 |
| `JWT_SECRET` | *필수* | JWT 서명 키 (최소 32자) |
| `MILMIL_ENCRYPTION_KEY` | *필수* | 스토리지 자격 증명용 AES-256 키 |
| `API_PORT` | `8080` | API 서버 포트 |
| `DATA_DIR` | `./data` | 다운로드 및 트랜스코드 캐시 |

모든 옵션은 [설정](/docs/configuration/environment)을 참조하세요.
