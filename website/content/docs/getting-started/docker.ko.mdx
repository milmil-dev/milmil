## 프로덕션 설정

프로덕션 compose 파일을 사용하여 전체 배포를 수행합니다:

```bash
docker compose -f docker-compose.prod.yml up -d
```

### 필수 환경 변수

프로젝트 루트에 `.env` 파일을 생성합니다:

```bash
JWT_SECRET=your-secret-key-at-least-32-characters
MILMIL_ENCRYPTION_KEY=your-aes-256-encryption-key
DATABASE_URL=postgres://milmil:password@postgres:5432/milmil?sslmode=disable
```

### 서비스

프로덕션 스택에는 다음이 포함됩니다:

| 서비스 | 포트 | 설명 |
|---------|------|-------------|
| `milmil-api` | 8080 | Go 백엔드 API |
| `milmil-web` | 3000 | React 프론트엔드 |
| `postgres` | 5432 | PostgreSQL 16 |
| `redis` | 6379 | Redis 7 캐시 |

### 리버스 프록시

HTTPS를 활성화하려면 milmil을 Nginx 또는 Caddy 뒤에 배치합니다. Nginx 설정 예시:

```nginx
server {
    listen 443 ssl;
    server_name milmil.example.com;

    location / {
        proxy_pass http://localhost:3000;
    }

    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    location /ws {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

### 볼륨 마운트

미디어 디렉토리를 컨테이너에 매핑합니다:

```yaml
volumes:
  - /path/to/anime:/media/anime
  - milmil-data:/data
```

### 데이터베이스

- **개발 환경**: SQLite (설정 불필요)
- **프로덕션 환경**: PostgreSQL 16+ 권장
- 시작 시 golang-migrate를 통해 마이그레이션이 자동 적용됩니다
