## 什麼是 milmil？

milmil 是一個自架的動漫媒體伺服器，讓你管理、探索和串流你的動漫收藏。它結合了媒體庫管理與彈幕、自動下載和多來源元資料匹配等進階功能。

## 核心功能

- **媒體庫管理** — 多儲存來源（本機、SMB、SFTP、40+ 雲端後端透過 rclone）自動掃描和元資料匹配
- **串流播放** — 直接播放、容器轉封裝（MKV 到 MP4）、FFmpeg HLS 轉碼
- **彈幕** — 來自彈彈Play的即時彈幕疊加
- **自動下載** — 內建種子客戶端、RSS 訂閱、聚合種子搜尋（Nyaa、DMHY、蜜柑等）
- **探索** — 季度日曆、熱門排行、全文搜尋與類型/標籤篩選
- **收藏** — 觀看狀態追蹤、個人評分、與 Bangumi 和 AniList 同步
- **多語言** — 完整 i18n 支援英語、日語、韓語、簡體中文、繁體中文
- **PWA** — 可安裝的漸進式網頁應用

## 快速開始

```bash
docker compose up -d
```

然後開啟 `http://localhost:3000` 並按照設定精靈操作。
