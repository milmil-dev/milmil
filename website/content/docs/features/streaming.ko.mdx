## 재생 모드

milmil은 세 가지 스트리밍 모드를 지원하며, 최적의 옵션을 자동으로 선택합니다:

### 직접 재생

바이트 범위 요청으로 원본 파일을 직접 제공합니다. 트랜스코딩 오버헤드 없음 — 최고의 화질과 성능.

### 컨테이너 리먹스

MKV 컨테이너를 MP4로 실시간 리먹스하며, 비디오나 오디오를 재인코딩하지 않습니다. MKV를 기본 지원하지 않는 브라우저에서의 재생을 가능하게 합니다.

### HLS 트랜스코딩

소스 형식이 브라우저와 호환되지 않을 때 FFmpeg로 HLS (HTTP 라이브 스트리밍)에 완전 트랜스코딩합니다. 포함 사항:

- 적응형 비트레이트 스트리밍
- 세션 기반 캐싱으로 빠른 탐색
- 구성 가능한 화질 프리셋

## 탄막 (탄막 코멘트)

DandanPlay에서 제공하는 실시간 탄막 코멘트가 비디오 위에 오버레이됩니다. 재생 중 화면을 가로질러 코멘트가 스크롤되며, 함께 시청하는 경험을 만듭니다.

플레이어 설정에서 탄막 밀도, 투명도, 글꼴 크기를 구성할 수 있습니다.

## 자막

milmil은 다음을 지원합니다:

- **내장 자막** — MKV/MP4 컨테이너에서 추출 (ASS, SRT 등)
- **외부 자막** — 비디오 옆의 `.srt`, `.ass`, `.vtt` 파일
- 언어 선택이 가능한 다중 자막 트랙

## 시청 진행

시청 진행 상황이 자동으로 저장 및 동기화됩니다:

- 어떤 기기에서든 이전에 보던 곳부터 이어서 시청
- 홈페이지에 이어서 보기 섹션 표시
- Bangumi 및 AniList와 진행 동기화 (연결 시)
