## 概览

milmil 的媒体库系统让你从多个存储后端组织和管理动画文件。文件会被自动扫描、识别，并使用来自 Bangumi、AniList 和 DandanPlay 的元数据匹配到动画条目。

## 存储后端

| 后端 | 说明 |
|---------|-------------|
| **本地** | 主机文件系统上的目录 |
| **SMB/CIFS** | Windows 网络共享 |
| **SFTP** | SSH 文件传输 |
| **FTP** | 标准 FTP |
| **WebDAV** | 云存储（Nextcloud 等） |
| **HTTP** | 直接 HTTP 文件访问 |
| **Rclone** | 40+ 云服务提供商（Google Drive、OneDrive、Dropbox、S3 等） |

## 扫描

扫描媒体库时，milmil 会：

1. 遍历目录树发现媒体文件
2. 使用 FFmpeg 提取元数据（编解码器、分辨率、时长、字幕）
3. 使用多个提供商将文件匹配到动画条目
4. 为剧集补充封面图片、标题和简介

扫描可以手动触发，也可以配置为自动运行。

## 元数据匹配

milmil 使用多提供商匹配管道：

1. **DandanPlay 哈希** — 最精确，通过文件哈希匹配
2. **Bangumi** — 基于标题的匹配，对照 Bangumi 数据库
3. **AniList** — 备选标题匹配
4. **TMDB** — 后备交叉引用

未匹配的文件可以在媒体库详情页手动匹配。

## 文件浏览器

媒体库详情页包含一个文件浏览器，显示：

- 目录树及文件数量
- 媒体文件详情（编解码器、分辨率、大小）
- 每个文件的匹配状态
- 批量匹配/取消匹配操作
