## 개요

milmil의 라이브러리 시스템을 사용하면 여러 스토리지 백엔드에서 애니메이션 파일을 정리하고 관리할 수 있습니다. 파일은 자동으로 스캔, 식별되며, Bangumi, AniList, DandanPlay의 메타데이터를 사용하여 애니메이션 항목에 매칭됩니다.

## 스토리지 백엔드

| 백엔드 | 설명 |
|---------|-------------|
| **로컬** | 호스트 파일 시스템의 디렉토리 |
| **SMB/CIFS** | Windows 네트워크 공유 |
| **SFTP** | SSH 파일 전송 |
| **FTP** | 표준 FTP |
| **WebDAV** | 클라우드 스토리지 (Nextcloud 등) |
| **HTTP** | 직접 HTTP 파일 접근 |
| **Rclone** | 40개 이상의 클라우드 제공업체 (Google Drive, OneDrive, Dropbox, S3 등) |

## 스캔

라이브러리를 스캔할 때 milmil은:

1. 디렉토리 트리를 탐색하여 미디어 파일 검색
2. FFmpeg로 메타데이터 추출 (코덱, 해상도, 재생 시간, 자막)
3. 여러 제공업체를 사용하여 파일을 애니메이션 항목에 매칭
4. 에피소드에 커버 이미지, 제목, 설명 보강

스캔은 수동으로 실행하거나 자동 실행으로 구성할 수 있습니다.

## 메타데이터 매칭

milmil은 다중 제공업체 매칭 파이프라인을 사용합니다:

1. **DandanPlay 해시** — 가장 정확, 파일 해시로 매칭
2. **Bangumi** — Bangumi 데이터베이스에 대한 제목 기반 매칭
3. **AniList** — 대체 제목 매칭
4. **TMDB** — 폴백 교차 참조

매칭되지 않은 파일은 라이브러리 상세 페이지에서 수동으로 매칭할 수 있습니다.

## 파일 브라우저

라이브러리 상세 페이지에는 다음을 표시하는 파일 브라우저가 포함됩니다:

- 파일 수가 표시된 디렉토리 트리
- 미디어 파일 상세 (코덱, 해상도, 크기)
- 각 파일의 매칭 상태
- 일괄 매칭/매칭 해제 작업
