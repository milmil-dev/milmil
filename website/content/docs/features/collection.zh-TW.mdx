---
title: 收藏
description: 追蹤你的動畫觀看進度、評分，並與外部服務同步。
---

## 觀看狀態

按狀態整理你的動畫：

| 狀態 | 說明 |
|--------|-------------|
| **在看** | 正在觀看 |
| **計劃看** | 計劃觀看 |
| **看過** | 已完成觀看 |
| **擱置** | 暫時擱置 |
| **拋棄** | 停止觀看 |

## 評分

按個人評分標準為動畫評分。評分與已連接的服務（Bangumi、AniList）雙向同步。

## 繼續觀看

首頁顯示你最近的觀看記錄：

- 劇集進度條
- 剩餘時間
- 一鍵繼續播放

## 外部同步

連接 Bangumi 或 AniList 後，你的收藏會自動同步：

- 觀看狀態變更同步到已連接的服務
- 評分雙向同步
- 進度即時更新

在 **設定 > 整合** 中設定同步。
