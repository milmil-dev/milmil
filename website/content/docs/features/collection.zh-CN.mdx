---
title: 收藏
description: 跟踪你的动画观看进度、评分，并与外部服务同步。
---

## 观看状态

按状态整理你的动画：

| 状态 | 说明 |
|--------|-------------|
| **在看** | 正在观看 |
| **计划看** | 计划观看 |
| **看过** | 已完成观看 |
| **搁置** | 暂时搁置 |
| **抛弃** | 停止观看 |

## 评分

按个人评分标准为动画评分。评分与已连接的服务（Bangumi、AniList）双向同步。

## 继续观看

首页显示你最近的观看记录：

- 剧集进度条
- 剩余时间
- 一键继续播放

## 外部同步

连接 Bangumi 或 AniList 后，你的收藏会自动同步：

- 观看状态变更同步到已连接的服务
- 评分双向同步
- 进度实时更新

在 **设置 > 集成** 中配置同步。
