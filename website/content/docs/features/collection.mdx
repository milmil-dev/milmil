## Watch Status

Organize your anime by status:

| Status | Description |
|--------|-------------|
| **Watching** | Currently watching |
| **Planning** | Plan to watch |
| **Completed** | Finished watching |
| **Paused** | On hold |
| **Dropped** | Stopped watching |

## Ratings

Rate anime on a personal scale. Ratings sync bidirectionally with connected services (Bangumi, AniList).

## Continue Watching

The home page shows your recent watch history with:

- Episode progress bars
- Time remaining
- One-click resume playback

## External Sync

When connected to Bangumi or AniList, your collection syncs automatically:

- Watch status changes propagate to connected services
- Scores sync bidirectionally
- Progress updates in real-time

Configure sync in **Settings > Integrations**.
