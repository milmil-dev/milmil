---
title: コレクション
description: アニメの視聴進捗、評価をトラッキングし、外部サービスと同期。
---

## 視聴ステータス

ステータスでアニメを整理：

| ステータス | 説明 |
|--------|-------------|
| **視聴中** | 現在視聴中 |
| **計画中** | 視聴予定 |
| **完了** | 視聴完了 |
| **一時停止** | 保留中 |
| **中断** | 視聴を中止 |

## 評価

個人のスケールでアニメを評価。評価は接続されたサービス（Bangumi、AniList）と双方向に同期されます。

## 視聴を再開

ホームページには最近の視聴履歴が表示されます：

- エピソード進捗バー
- 残り時間
- ワンクリックで再生を再開

## 外部同期

Bangumi または AniList に接続すると、コレクションが自動的に同期されます：

- 視聴ステータスの変更が接続サービスに反映
- スコアの双方向同期
- 進捗がリアルタイムで更新

同期は **設定 > 連携** で設定します。
