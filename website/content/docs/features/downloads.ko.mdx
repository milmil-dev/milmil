## 토렌트 클라이언트

milmil에는 다음 기능을 갖춘 토렌트 클라이언트가 내장되어 있습니다:

- 구성 가능한 시드 비율 및 시간 제한
- DHT 및 피어 교환 지원
- 다운로드 진행 추적
- 일시정지/재개 제어

### 설정

| 설정 | 기본값 | 설명 |
|---------|---------|-------------|
| `TORRENT_LISTEN_PORT` | `42069` | DHT/피어 포트 |
| `SEED_RATIO` | `1.0` | 목표 시드 비율 |
| `SEED_TIME_MINUTES` | `60` | 최소 시드 시간 |

## 토렌트 검색

단일 인터페이스에서 여러 토렌트 제공업체를 통합 검색:

- **Nyaa** — 최대 규모의 애니메이션 토렌트 트래커
- **DMHY** — 중국어 애니메이션 토렌트
- **Mikan** — Mikan Project 애그리게이터
- **Bangumi.moe** — Bangumi 토렌트 트래커
- **ACG.rip** — ACG 리소스 트래커

해상도, 자막 그룹, 파일 유형으로 결과를 필터링합니다.

## RSS 자동 다운로드

RSS 피드를 구독하여 에피소드를 자동 다운로드합니다:

1. RSS 피드 URL 추가
2. 필터 구성 (정규 표현식 패턴, 해상도, 자막 그룹 선호도)
3. milmil이 주기적으로 피드를 확인하고 매칭되는 에피소드를 다운로드
4. 다운로드된 파일이 자동으로 스캔 및 매칭

### 다운로드 후 파이프라인

다운로드 완료 후 milmil이 자동으로:

1. 다운로드된 파일 스캔
2. 올바른 애니메이션 및 에피소드에 매칭
3. 제공업체에서 메타데이터 보강
4. 알림 전송

## HTTP 다운로드

milmil은 재개 기능이 있는 직접 HTTP 다운로드도 지원합니다.
