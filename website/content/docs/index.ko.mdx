## milmil이란?

milmil은 애니메이션 컬렉션을 관리, 탐색, 스트리밍할 수 있는 셀프 호스팅 애니메이션 미디어 서버입니다. 라이브러리 관리와 함께 단막(탄막), 자동 다운로드, 멀티 프로바이더 메타데이터 매칭 등 고급 기능을 제공합니다.

## 주요 기능

- **라이브러리 관리** — 다중 저장소 (로컬, SMB, SFTP, rclone을 통한 40+ 클라우드 백엔드) 자동 스캔 및 메타데이터 매칭
- **스트리밍** — 직접 재생, 컨테이너 리먹싱 (MKV에서 MP4), FFmpeg HLS 트랜스코딩
- **단막** — DandanPlay의 실시간 탄막 오버레이
- **자동 다운로드** — 내장 토렌트 클라이언트, RSS 구독, Nyaa, DMHY, Mikan 등 통합 토렌트 검색
- **탐색** — 시즌 캘린더, 트렌딩 랭킹, 장르/태그 필터 전체 텍스트 검색
- **컬렉션** — 시청 상태 추적, 개인 평점, Bangumi 및 AniList 동기화
- **다국어** — 영어, 일본어, 한국어, 중국어 간체/번체 완전 i18n 지원
- **PWA** — 설치 가능한 프로그레시브 웹 앱

## 빠른 시작

```bash
docker compose up -d
```

`http://localhost:3000`을 열고 설정 마법사를 따라하세요.
