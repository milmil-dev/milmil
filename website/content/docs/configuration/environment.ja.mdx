## コア設定

| 変数 | デフォルト | 説明 |
|----------|---------|-------------|
| `DATABASE_URL` | `sqlite://data/milmil.db` | データベース接続（SQLite または PostgreSQL） |
| `JWT_SECRET` | *必須* | JWT 署名キー（最低 32 文字） |
| `MILMIL_ENCRYPTION_KEY` | *必須* | ストレージ認証情報用 AES-256 キー |
| `API_PORT` | `8080` | API サーバーポート |
| `DATA_DIR` | `./data` | ダウンロードとトランスコードキャッシュ |
| `DEBUG` | `0` | デバッグログを有効化 |
| `REDIS_URL` | — | Redis 接続 URL（未設定時はインメモリキャッシュ） |

## Torrent 設定

| 変数 | デフォルト | 説明 |
|----------|---------|-------------|
| `TORRENT_LISTEN_PORT` | `42069` | Torrent DHT/ピアポート |
| `SEED_RATIO` | `1.0` | 停止前の目標シード率 |
| `SEED_TIME_MINUTES` | `60` | 最小シード時間（分） |

## 連携キー

| 変数 | デフォルト | 説明 |
|----------|---------|-------------|
| `DANDANPLAY_APP_ID` | — | DandanPlay API アプリ ID |
| `DANDANPLAY_APP_SECRET` | — | DandanPlay API アプリシークレット |

## データベース

milmil は 2 つのデータベースバックエンドに対応しています：

- **SQLite** — 設定不要、開発や小規模環境に最適
- **PostgreSQL 16+** — 本番環境に推奨

```bash
# SQLite（デフォルト）
DATABASE_URL=sqlite://data/milmil.db

# PostgreSQL
DATABASE_URL=postgres://user:password@localhost:5432/milmil?sslmode=disable
```

## Redis

Redis はオプションですが、本番環境では推奨です。Redis がない場合、milmil はインメモリキャッシュを使用しますが、再起動後は永続化されません。

```bash
REDIS_URL=redis://localhost:6379
```
