title: 連携

## Bangumi

[Bangumi](https://bangumi.tv) はアニメのメタデータ、評価、コレクション同期を提供します。

### セットアップ

1. **設定 > 連携** に移動
2. **Bangumi に接続** をクリック
3. Bangumi OAuth フローで milmil を認可
4. コレクションが自動的に同期されます

### 機能

- アニメメタデータ（タイトル、あらすじ、スコア、エピソード数）
- 視聴ステータス同期（計画中、視聴中、完了など）
- スコア同期

## AniList

[AniList](https://anilist.co) は代替のメタデータおよびトラッキングサービスです。

### セットアップ

1. **設定 > 連携** に移動
2. **AniList に接続** をクリック
3. AniList OAuth フローで milmil を認可

### 機能

- アニメメタデータとカバー画像
- 視聴進捗同期
- スコア同期

## DandanPlay

[DandanPlay](https://www.dandanplay.com) はファイルハッシュベースのマッチングと弾幕（弾幕コメント）を提供します。

### セットアップ

DandanPlay デベロッパーポータルで API 認証情報を登録し、環境変数を設定します：

```bash
DANDANPLAY_APP_ID=your_app_id
DANDANPLAY_APP_SECRET=your_app_secret
```

### 機能

- ファイルハッシュマッチング — 最も正確なエピソード識別
- 再生中の弾幕オーバーレイ
- エピソードメタデータ

## TMDB

[TMDB](https://www.themoviedb.org) は TV 番組メタデータのクロスリファレンス用フォールバックとして使用されます。設定は不要です。
