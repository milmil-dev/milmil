## Bangumi

[Bangumi](https://bangumi.tv)는 애니메이션 메타데이터, 평점 및 컬렉션 동기화를 제공합니다.

### 설정

1. **설정 > 연동**으로 이동
2. **Bangumi 연결** 클릭
3. Bangumi OAuth 플로우에서 milmil 인가
4. 컬렉션이 자동으로 동기화됩니다

### 기능

- 애니메이션 메타데이터 (제목, 설명, 평점, 에피소드 수)
- 시청 상태 동기화 (계획, 시청 중, 완료 등)
- 평점 동기화

## AniList

[AniList](https://anilist.co)는 대체 메타데이터 및 추적 서비스입니다.

### 설정

1. **설정 > 연동**으로 이동
2. **AniList 연결** 클릭
3. AniList OAuth 플로우에서 milmil 인가

### 기능

- 애니메이션 메타데이터 및 커버 이미지
- 시청 진행 동기화
- 평점 동기화

## DandanPlay

[DandanPlay](https://www.dandanplay.com)는 파일 해시 기반 매칭과 탄막 (탄막 코멘트)을 제공합니다.

### 설정

DandanPlay 개발자 포털에서 API 자격 증명을 등록한 후 환경 변수를 설정합니다:

```bash
DANDANPLAY_APP_ID=your_app_id
DANDANPLAY_APP_SECRET=your_app_secret
```

### 기능

- 파일 해시 매칭 — 가장 정확한 에피소드 식별
- 재생 중 탄막 오버레이
- 에피소드 메타데이터

## TMDB

[TMDB](https://www.themoviedb.org)는 TV 프로그램 메타데이터의 교차 참조 폴백으로 사용됩니다. 별도 설정이 필요 없습니다.
